## 1. MRO и C3-линеаризация

**MRO (Method Resolution Order)** — порядок, в котором Python ищет методы и атрибуты в иерархии классов. С Python 2.3 используется **C3-линеаризация**.

```python
class A: pass
class B(A): pass
class C(A): pass
class D(B, C): pass

print(D.__mro__)
# D → B → C → A → object
```

Правила C3:
1. Класс идёт раньше своих родителей.
2. Сохраняется порядок родителей из объявления.
3. При противоречии — `TypeError` (несовместимая иерархия).

**Ромбовидное наследование:**
```python
class A:
    def m(self): print("A")
class B(A):
    def m(self): print("B")
class C(A):
    def m(self): print("C")
class D(B, C): pass

D().m()   # "B" — MRO: D, B, C, A
```

## 2. `super()` — не просто родитель

`super()` возвращает прокси, который делегирует вызов **следующему классу в MRO**, а не обязательно прямому родителю.

```python
class A:
    def m(self): print("A")
class B(A):
    def m(self):
        print("B")
        super().m()
class C(A):
    def m(self):
        print("C")
        super().m()
class D(B, C):
    def m(self):
        print("D")
        super().m()

D().m()   # D → B → C → A  (кооперативное наследование)
```

## 3. Абстрактные классы и протоколы

```python
from abc import ABC, abstractmethod

class Shape(ABC):
    @abstractmethod
    def area(self): ...

class Circle(Shape):
    def __init__(self, r): self.r = r
    def area(self): return 3.14 * self.r ** 2

# Shape()  # TypeError — нельзя создать абстрактный класс
```

**Protocol** — структурная типизация (утиная типизация, проверяемая статически):
```python
from typing import Protocol

class Flyer(Protocol):
    def fly(self) -> None: ...

def take_off(obj: Flyer):
    obj.fly()
```

## 4. Метаклассы

Класс класса. По умолчанию метакласс — `type`.

```python
MyClass = type("MyClass", (), {"x": 10})   # эквивалент class MyClass: x = 10

class Meta(type):
    def __new__(mcls, name, bases, dct):
        dct["version"] = 1.0
        return super().__new__(mcls, name, bases, dct)

class Foo(metaclass=Meta): pass
Foo.version   # 1.0
```

**Где нужны:** ORM (SQLAlchemy/Django собирают поля моделей), регистрация классов/плагинов, валидация интерфейса. В обычном коде — редко.

## 5. `__slots__`

Ограничивает набор атрибутов и экономит память (вместо `__dict__` — слоты).

```python
class Point:
    __slots__ = ("x", "y")
    def __init__(self, x, y):
        self.x, self.y = x, y

p = Point(1, 2)
# p.z = 3   # AttributeError — нельзя добавлять новые атрибуты
```

Минусы: нет `__dict__`, сложнее с наследованием/множественным наследованием.

## 6. SOLID

| Принцип | Суть |
|---|---|
| **S**RP — единственная ответственность | У класса одна причина для изменения |
| **O**CP — открыт/закрыт | Расширяй через наследование, не меняя существующий код |
| **L**SP — подстановка Лисков | Наследник заменяет родителя без поломок |
| **I**SP — разделение интерфейсов | Не заставляй зависеть от неиспользуемых методов |
| **D**IP — инверсия зависимостей | Зависи от абстракций, не от конкретных классов |

**Пример DIP (инъекция зависимости):**
```python
class Notifier(ABC):
    @abstractmethod
    def send(self, msg): ...

class EmailNotifier(Notifier):
    def send(self, msg): print(f"Email: {msg}")

class UserService:
    def __init__(self, notifier: Notifier):   # зависим от абстракции
        self.notifier = notifier
```

## 7. Паттерны проектирования (минимум для собеса)

**Singleton** — один экземпляр на всё приложение.
```python
class Singleton:
    _instance = None
    def __new__(cls):
        if cls._instance is None:
            cls._instance = super().__new__(cls)
        return cls._instance
```

**Factory** — создание объектов без указания конкретного класса.
```python
class Dog: ...
class Cat: ...

def create_animal(kind):
    return {"dog": Dog, "cat": Cat}[kind]()
```

**Abstract Factory** — фабрика, создающая семейства связанных объектов.
```python
class GUIFactory(ABC):
    @abstractmethod
    def button(self): ...
    @abstractmethod
    def checkbox(self): ...

class WinFactory(GUIFactory):
    def button(self): return WinButton()
    def checkbox(self): return WinCheckbox()
```

**Observer**, **Strategy**, **Decorator** — тоже частые вопросы. Начни с Singleton + Factory + Strategy.
