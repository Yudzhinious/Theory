## 1. Вариативность (variance)

- **Ковариантность** — `Sequence[Dog]` можно использовать как `Sequence[Animal]` (только чтение).
- **Контравариантность** — аргументы функций.
- **Инвариантность** — `list` изменяемый → `list[Dog]` **не** является `list[Animal]`.

```python
from typing import Sequence
def feed(animals: Sequence[Animal]) -> None: ...
feed([Dog()])   # ок, Sequence ковариантен
```

## 2. Продвинутые конструкции `typing`

| Конструкция | Назначение |
|---|---|
| `ParamSpec` | типизация декораторов (сохраняет сигнатуру) |
| `Concatenate` | добавляет аргумент к `ParamSpec` |
| `@overload` | несколько сигнатур для одной функции |
| `Annotated[T, meta]` | тип + метаданные (валидация, DI) |
| `Self` | возвращаемый тип = текущий класс |
| `Never` / `NoReturn` | функция не возвращает управление |
| `TypeGuard` | сужение типа |
| `TypedDict` + `NotRequired`/`Required` | частичные словари |
| `Protocol` + `TypeVar` | дженерик-протоколы |

```python
from typing import overload, Annotated, Self, TypeVar

@overload
def parse(x: int) -> int: ...
@overload
def parse(x: str) -> str: ...
def parse(x): return x

UserId = Annotated[int, "pk"]

class Builder:
    def add(self) -> Self:
        return self
```

**Декоратор с `ParamSpec`:**
```python
from typing import ParamSpec, TypeVar, Callable
P, R = ParamSpec("P"), TypeVar("R")
def logged(f: Callable[P, R]) -> Callable[P, R]:
    def wrapper(*a: P.args, **k: P.kwargs) -> R:
        return f(*a, **k)
    return wrapper
```

## 3. Forward references и `TYPE_CHECKING`

```python
from __future__ import annotations   # отложенные аннотации (строки)

from typing import TYPE_CHECKING
if TYPE_CHECKING:
    from expensive import Heavy   # импорт только для типов, не в рантайме
```

## 4. `dataclasses` глубоко

```python
from dataclasses import dataclass, field, InitVar

@dataclass(slots=True, frozen=True)
class Point:
    x: int
    y: int = 0
    tags: list[str] = field(default_factory=list)
    raw: InitVar[str] = ""

    def __post_init__(self, raw):
        ...
```

- `slots=True` (3.10+) — экономия памяти.
- `frozen=True` — неизменяемость + `__hash__`.
- `InitVar` — параметр только для `__post_init__`.
- Наследование: поля с дефолтами должны идти после полей без дефолтов.

## 5. Pydantic vs dataclass vs attrs

| | dataclass | attrs | Pydantic |
|---|---|---|---|
| Валидация | нет | опц. | да |
| Парсинг/сериализация | нет | частично | да |
| Скорость | высокая | высокая | v2 быстрая |
| Рантайм-проверки | нет | нет | да |

## 6. mypy и строгий режим

```ini
# mypy.ini
[mypy]
strict = True
warn_unused_ignores = True
disallow_untyped_defs = True
```

- `# type: ignore[code]` — точечно подавить.
- **Stubs** (`.pyi`) для неаннотированных библиотек; **`py.typed`** маркер в пакете.
- `reveal_type(x)` — показать выведенный тип.

## 7. Где типы работают в рантайме

- **Pydantic/FastAPI** читают `__annotations__` для валидации/OpenAPI.
- **`typing.get_type_hints(func)`** — получить типы.
- `Annotated` + метаданные используют DI-фреймворки.
- `@runtime_checkable` Protocol — `isinstance` по наличию методов.
