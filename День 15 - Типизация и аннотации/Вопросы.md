# День 15 — Вопросы

---

**1. Влияют ли аннотации типов на выполнение кода?**
<details><summary>Ответ</summary>
Сами по себе — нет, Python не проверяет их в рантайме. Но библиотеки (Pydantic, FastAPI) читают `__annotations__` и используют их для валидации/документации.
</details>

**2. Что такое `Optional[str]`?**
<details><summary>Ответ</summary>
То же, что `Union[str, None]` — значение типа `str` или `None`. С 3.10 можно писать `str | None`.
</details>

**3. `Union` vs `Literal`?**
<details><summary>Ответ</summary>
`Union[int, str]` — значение одного из типов. `Literal["r", "w"]` — значение строго из перечисленных конкретных значений.
</details>

**4. Зачем `TypeVar` и `Generic`?**
<details><summary>Ответ</summary>
Для обобщённого кода: `TypeVar` связывает типы (например, тип элемента и тип возврата), `Generic` позволяет создавать дженерик-классы вроде `Stack[T]`.
</details>

**5. `Protocol` vs `ABC`?**
<details><summary>Ответ</summary>
`ABC` требует наследования и проверяет в рантайме. `Protocol` — структурная типизация: подходит любой объект с нужными методами, проверяется статически (утиная типизация с типами).
</details>

**6. Что такое `TypedDict`?**
<details><summary>Ответ</summary>
Аннотированный словарь с фиксированным набором ключей и их типов. Позволяет типизировать структуры, которые должны быть словарями.
</details>

**7. Чем `dataclass` отличается от Pydantic-модели?**
<details><summary>Ответ</summary>
`dataclass` генерирует `__init__`/`__repr__`/`__eq__`, но не валидирует типы. Pydantic валидирует и преобразует данные в рантайме (используется в FastAPI).
</details>

**8. Как задать изменяемое значение по умолчанию в `dataclass`?**
<details><summary>Ответ</summary>
Через `field(default_factory=list)` — иначе изменяемый объект был бы общим для всех экземпляров.
</details>

**9. Что делает mypy?**
<details><summary>Ответ</summary>
Статически проверяет типы по аннотациям, не запуская код. Находит несоответствия до выполнения.
</details>

**10. Как прочитать аннотации функции во время выполнения?**
<details><summary>Ответ</summary>
`func.__annotations__` — словарь с типами аргументов и возврата.
</details>

## Мини-задача
Опиши тип функции, принимающей список чисел и возвращающей их среднее (или `None`, если список пуст).
<details><summary>Решение</summary>

```python
from typing import Optional

def average(nums: list[float]) -> Optional[float]:
    if not nums:
        return None
    return sum(nums) / len(nums)
```
</details>
