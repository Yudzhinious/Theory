# День 8 — Вопросы

---

**1. Как Python управляет памятью?**
<details><summary>Ответ</summary>
Основной механизм — подсчёт ссылок (объект удаляется, когда refcount = 0). Дополнительно циклический сборщик мусора ищет недостижимые циклы, используя поколения.
</details>

**2. Что такое циклическая ссылка и как с ней бороться?**
<details><summary>Ответ</summary>
Два и более объекта ссылаются друг на друга, refcount не падает до 0. Решения: циклический GC (`gc.collect()`) или слабые ссылки `weakref`.
</details>

**3. Что такое GIL?**
<details><summary>Ответ</summary>
Global Interpreter Lock — мьютекс CPython, позволяющий в один момент выполняться байт-коду только одного потока. Ограничивает параллелизм CPU-задач в потоках.
</details>

**4. Почему потоки не ускоряют CPU-задачи, но помогают с I/O?**
<details><summary>Ответ</summary>
GIL пропускает только один поток к байт-коду, поэтому CPU-потоки идут по очереди. Во время I/O (сеть, диск) GIL отпускается, и другие потоки работают — поэтому I/O ускоряется.
</details>

**5. Как обойти GIL для CPU-задач?**
<details><summary>Ответ</summary>
`multiprocessing` (свой интерпретатор и GIL у каждого процесса), C-расширения, отпускающие GIL (NumPy, Pandas), `numba`, `Cython`.
</details>

**6. Что такое Big-O? Что сложнее: O(n log n) или O(n²)?**
<details><summary>Ответ</summary>
Асимптотическая оценка роста времени/памяти. O(n²) хуже O(n log n) при больших n.
</details>

**7. Назови сложность доступа к элементу `list` и `dict`.**
<details><summary>Ответ</summary>
`list` по индексу — O(1); `dict` по ключу — O(1) в среднем (хеш-таблица).
</details>

**8. Что такое Timsort? Стабильна ли сортировка в Python?**
<details><summary>Ответ</summary>
Гибрид merge sort и insertion sort, O(n log n), использует уже упорядоченные runs. Сортировка Python стабильна — равные элементы сохраняют относительный порядок.
</details>

**9. Зачем нужна стабильность сортировки?**
<details><summary>Ответ</summary>
Позволяет сортировать по нескольким ключам последовательно: сначала по второстепенному, затем по главному — порядок равных сохранится.
</details>

**10. Что такое динамическое программирование?**
<details><summary>Ответ</summary>
Метод решения задач через разбиение на перекрывающиеся подзадачи с запоминанием результатов (мемоизация/таблица). Пример — числа Фибоначчи, задача о рюкзаке.
</details>

## Мини-задача
Реализуй бинарный поиск и оцени сложность. Найди индекс числа 7 в `[1, 3, 5, 7, 9]`.
<details><summary>Решение</summary>

```python
def binary_search(arr, target):
    lo, hi = 0, len(arr) - 1
    while lo <= hi:
        mid = (lo + hi) // 2
        if arr[mid] == target:
            return mid
        elif arr[mid] < target:
            lo = mid + 1
        else:
            hi = mid - 1
    return -1

binary_search([1, 3, 5, 7, 9], 7)   # 3
# Сложность: O(log n)
```
</details>
