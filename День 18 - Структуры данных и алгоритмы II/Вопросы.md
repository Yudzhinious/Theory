# День 18 — Вопросы

---

**1. Стек vs очередь?**
<details><summary>Ответ</summary>
Стек — LIFO (последний пришёл, первый вышел), очередь — FIFO. Стек реализуют через `list`, очередь — через `collections.deque`.
</details>

**2. Почему `list.pop(0)` медленный?**
<details><summary>Ответ</summary>
Удаление из начала сдвигает все остальные элементы — O(n). Для очередей используют `deque` с O(1) на `popleft()`.
</details>

**3. Связный список vs массив (`list`)?**
<details><summary>Ответ</summary>
Массив — непрерывная память, доступ O(1), вставка в середину O(n). Связный список — доступ O(n), вставка/удаление при известном узле O(1), больше накладных расходов.
</details>

**4. Что такое BST и его сложности?**
<details><summary>Ответ</summary>
Бинарное дерево поиска: левое поддерево < узел < правое. Поиск/вставка/удаление O(log n) в среднем, O(n) при вырождении. Сбалансированные деревья держат O(log n).
</details>

**5. Что такое куча (heap)?**
<details><summary>Ответ</summary>
Двоичное дерево (обычно min-heap) с минимумом в корне. Минимум — O(1), вставка/извлечение — O(log n). Реализуется через `heapq`.
</details>

**6. BFS vs DFS?**
<details><summary>Ответ</summary>
BFS (очередь) обходит по уровням, находит кратчайший путь в невзвешенном графе. DFS (стек/рекурсия) идёт вглубь, полезен для обхода/поиска циклов.
</details>

**7. Как представить граф в коде?**
<details><summary>Ответ</summary>
Списком смежности (`dict[вершина] -> list соседей`) — экономно; или матрицей смежности — быстро проверять наличие ребра, но O(V²) памяти.
</details>

**8. Что такое рекурсия и что обязательно нужно?**
<details><summary>Ответ</summary>
Функция вызывает себя. Нужен базовый случай для остановки; глубина ограничена (риск `RecursionError`).
</details>

**9. Что такое мемоизация?**
<details><summary>Ответ</summary>
Кэширование результатов функции для повторных вызовов с теми же аргументами. `functools.lru_cache` превращает экспоненциальный Фибоначчи в O(n).
</details>

**10. Сложность поиска в `dict` и в BST?**
<details><summary>Ответ</summary>
`dict` — O(1) в среднем (хеш). BST — O(log n) в среднем, O(n) в худшем.
</details>

## Мини-задача
Проверь, сбалансированы ли скобки в строке `"({[]})"`, используя стек.
<details><summary>Решение</summary>

```python
def is_balanced(s: str) -> bool:
    pairs = {")": "(", "]": "[", "}": "{"}
    stack = []
    for ch in s:
        if ch in "([{":
            stack.append(ch)
        elif ch in pairs:
            if not stack or stack.pop() != pairs[ch]:
                return False
    return not stack

print(is_balanced("({[]})"))   # True
print(is_balanced("(]"))       # False
```
</details>
