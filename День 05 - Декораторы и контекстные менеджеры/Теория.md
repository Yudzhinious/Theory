## 1. Что такое декоратор

Декоратор — функция, которая принимает функцию и возвращает новую (обёртку). Синтаксис `@deco` — это сахар для `func = deco(func)`.

```python
import time
from functools import wraps

def timer(func):
    @wraps(func)
    def wrapper(*args, **kwargs):
        start = time.perf_counter()
        result = func(*args, **kwargs)
        print(f"{func.__name__}: {time.perf_counter() - start:.4f}s")
        return result
    return wrapper

@timer
def slow_sum(n):
    return sum(range(n))

slow_sum(1_000_000)
```

**Зачем `@wraps`:** без него обёртка подменяет `__name__`, `__doc__`, аннотации исходной функции. `wraps` копирует метаданные.

## 2. Декоратор с аргументами

Нужен дополнительный уровень вложенности: внешняя функция принимает параметры и возвращает декоратор.

```python
def repeat(times):
    def decorator(func):
        @wraps(func)
        def wrapper(*args, **kwargs):
            for _ in range(times):
                result = func(*args, **kwargs)
            return result
        return wrapper
    return decorator

@repeat(3)
def greet(name):
    print(f"Привет, {name}!")

greet("Аня")   # напечатает 3 раза
```

Порядок вызовов: `repeat(3)` → `decorator` → `wrapper`.

## 3. Цепочка декораторов

Применяются **снизу вверх**:

```python
@deco_A
@deco_B
def f(): ...
# эквивалентно: f = deco_A(deco_B(f))
```

Сначала оборачивает `deco_B`, затем `deco_A`.

## 4. Классические применения

- логирование и замер времени;
- кэширование (`@functools.lru_cache`);
- проверка прав/аутентификация;
- повторные попытки (retry);
- регистрация функций (роуты во фреймворках: `@app.get("/")`).

```python
from functools import lru_cache

@lru_cache(maxsize=None)
def fib(n):
    return n if n < 2 else fib(n-1) + fib(n-2)
```

## 5. Контекстный менеджер

Объект, управляющий ресурсом через `with`. Реализует `__enter__` и `__exit__`.

```python
with open("file.txt") as f:
    data = f.read()
# файл гарантированно закрыт, даже при исключении
```

**Протокол:**
- `__enter__(self)` — вызывается при входе, результат попадает в переменную после `as`.
- `__exit__(self, exc_type, exc_val, exc_tb)` — вызывается при выходе; если вернуть `True`, исключение **подавляется**.

---

## 6. Свой контекстный менеджер

**Через класс:**
```python
class ManagedFile:
    def __init__(self, path, mode="r"):
        self.path, self.mode = path, mode
    def __enter__(self):
        self.file = open(self.path, self.mode)
        return self.file
    def __exit__(self, exc_type, exc_val, exc_tb):
        self.file.close()
        return False   # исключение не подавляем

with ManagedFile("data.txt", "w") as f:
    f.write("hello")
```

**Через `@contextmanager` (проще):**
```python
from contextlib import contextmanager

@contextmanager
def timer(name):
    import time
    start = time.perf_counter()
    try:
        yield
    finally:
        print(f"{name}: {time.perf_counter() - start:.4f}s")

with timer("sleep"):
    import time; time.sleep(0.5)
```

Всё до `yield` — это `__enter__`, всё после — `__exit__`.

## 7. Полезные готовые менеджеры

| Менеджер | Назначение |
|---|---|
| `open()` | файлы |
| `threading.Lock` | блокировки |
| `contextlib.suppress` | подавление исключений |
| `contextlib.redirect_stdout` | перенаправление вывода |
| `unittest.mock.patch` | подмена объектов в тестах |
| `asyncio.timeout` | таймауты (3.11+) |

```python
from contextlib import suppress
with suppress(FileNotFoundError):
    import os; os.remove("no_file.txt")   # ошибка не всплывёт
```
