# День 3 — Вопросы

---

**1. Что такое `*args` и `**kwargs`?**
<details><summary>Ответ</summary>
`*args` собирает лишние позиционные аргументы в кортеж, `**kwargs` — именованные в словарь. Позволяют писать функции с произвольным числом аргументов.
</details>

**2. В чём опасность изменяемого значения по умолчанию?**
```python
def f(x, acc=[]):
    acc.append(x); return acc
```
<details><summary>Ответ</summary>
Значение по умолчанию вычисляется один раз при определении функции, поэтому список переиспользуется между вызовами. Нужно `acc=None` и создавать список внутри.
</details>

**3. Объясни правило LEGB.**
<details><summary>Ответ</summary>
Порядок поиска имени: Local → Enclosing → Global → Built-in. Python берёт первое найденное.
</details>

**4. `global` и `nonlocal` — в чём разница?**
<details><summary>Ответ</summary>
`global` меняет переменную модуля; `nonlocal` — переменную ближайшей внешней (объёмлющей) функции. Оба нужны только при присваивании.
</details>

**5. Что выведет и почему?**
```python
funcs = [lambda: i for i in range(3)]
print([f() for f in funcs])
```
<details><summary>Ответ</summary>
`[2, 2, 2]`. Все лямбды захватывают одну и ту же переменную `i`, а к моменту вызова цикл завершился на `i = 2`. Лечится `lambda i=i: i`.
</details>

**6. Что такое замыкание?**
<details><summary>Ответ</summary>
Функция вместе с захваченным окружением (переменными внешней функции). Внешняя функция может уже завершиться, но значения сохраняются.
</details>

**7. Что такое функция первого класса?**
<details><summary>Ответ</summary>
Функция — обычный объект: её можно присвоить переменной, передать как аргумент, вернуть из функции, положить в структуру.
</details>

**8. Можно ли изменить глобальный список внутри функции без `global`?**
<details><summary>Ответ</summary>
Да, если не переприсваивать имя, а изменять объект (`append`, `[i] = ...`). `global` нужен только для присваивания нового значения переменной.
</details>

**9. Что делает `sorted(nums, key=lambda x: -x)`?**
<details><summary>Ответ</summary>
Сортирует по убыванию: `key` возвращает отрицание, и большие числа получают меньший ключ.
</details>

**10. Чем `map`/`filter` отличаются от list comprehension?**
<details><summary>Ответ</summary>
Функционально похожи. Comprehension обычно читаемее и быстрее; `map`/`filter` возвращают ленивые итераторы.
</details>

## Мини-задача
Напиши функцию-счётчик `make_counter()`, которая при каждом вызове возвращает следующее число (1, 2, 3, ...).
<details><summary>Решение</summary>

```python
def make_counter():
    n = 0
    def step():
        nonlocal n
        n += 1
        return n
    return step

c = make_counter()
c(), c(), c()   # (1, 2, 3)
```
</details>
