# День 3 — Функции и области видимости

> Цель: понимать, как передаются аргументы, как работает поиск имён (LEGB) и что такое замыкания.

## 0. Как читать этот конспект

Функции — центральная единица организации кода. На собеседовании проверяют три вещи: **как передаются аргументы**, **как Python ищет имена** и **что такое замыкание**. Все три темы связаны: замыкание — это следствие правил поиска имён и передачи ссылок.

---

## 1. Определение и вызов

```python
def greet(name, greeting="Привет"):
    """Документация функции."""
    return f"{greeting}, {name}!"

greet("Аня")                 # 'Привет, Аня!'
greet("Аня", greeting="Хай") # 'Хай, Аня!'
```

- `def` создаёт объект-функцию и привязывает имя.
- Функции — **объекты первого класса**: их можно присваивать, передавать, возвращать.

### Разбор определения

```python
def greet(name, greeting="Привет"):
    """Документация функции."""
    return f"{greeting}, {name}!"

print(greet.__name__)    # greet
print(greet.__doc__)     # Документация функции.
print(type(greet))       # <class 'function'>
```

### Функция — это объект

```python
def square(x):
    return x * x

f = square            # присвоили функции другое имя
print(f(4))           # 16

def apply(func, value):
    return func(value)

print(apply(square, 5))   # 25 — передали функцию как аргумент
```

### Аргументы по умолчанию

```python
def power(base, exp=2):
    return base ** exp

print(power(3))       # 9  — exp=2
print(power(3, 3))    # 27
```

### Мини-итог

Функция — полноценный объект: у неё есть имя, документация, тип. Её можно хранить в переменной, передавать и возвращать.

## 2. Аргументы: `*args` и `**kwargs`

```python
def func(pos, *args, key=1, **kwargs):
    print(pos, args, key, kwargs)

func(1, 2, 3, key=9, a=10, b=20)
# 1 (2, 3) 9 {'a': 10, 'b': 20}
```

- `*args` — позиционные аргументы как **кортеж**.
- `**kwargs` — именованные как **словарь**.
- Параметры после `*` — **только именованные** (keyword-only).

**Распаковка при вызове:**
```python
def add(a, b): return a + b
args = (2, 3); kwargs = {"a": 2, "b": 3}
add(*args)      # 5
add(**kwargs)   # 5
```

**Ловушка изменяемого аргумента по умолчанию:**
```python
def bad(x, acc=[]):     # ❌ список создаётся один раз!
    acc.append(x)
    return acc
bad(1)   # [1]
bad(2)   # [1, 2]  ← неожиданно

def good(x, acc=None):  # ✅
    if acc is None:
        acc = []
    acc.append(x)
    return acc
```

### Пошаговый разбор `*args`

```python
def total(*args):
    print(type(args))     # <class 'tuple'>
    return sum(args)

print(total(1, 2, 3))     # 6
print(total())            # 0 — пустой кортеж
```

### Пошаговый разбор `**kwargs`

```python
def show(**kwargs):
    print(type(kwargs))   # <class 'dict'>
    for key, value in kwargs.items():
        print(f"{key} = {value}")

show(name="Аня", age=25)
# name = Аня
# age = 25
```

### Keyword-only аргументы

```python
def connect(host, *, timeout=5, retries=3):
    return f"{host} timeout={timeout} retries={retries}"

print(connect("db"))                 # db timeout=5 retries=3
print(connect("db", timeout=10))     # db timeout=10 retries=3
# connect("db", 10)                  # ❌ TypeError — только по имени
```

### Распаковка при вызове

```python
def add(a, b, c):
    return a + b + c

nums = [1, 2, 3]
print(add(*nums))              # 6 — список распакован в позиционные

opts = {"a": 1, "b": 2, "c": 3}
print(add(**opts))             # 6 — словарь распакован в именованные
```

### Почему `acc=[]` опасен

Значения по умолчанию вычисляются **один раз при определении функции** и хранятся в самой функции. Поэтому один и тот же список живёт между вызовами.

```python
def bad(x, acc=[]):
    acc.append(x)
    return acc

print(bad(1))     # [1]
print(bad(2))     # [1, 2]  ← список тот же самый
print(bad.__defaults__)   # ([1, 2],) — видно, что накопилось
```

### Типичная ошибка

```python
# ❌ Опасный дефолт
def add_item(item, cart=[]):
    cart.append(item)
    return cart

# ✅ Безопасный дефолт
def add_item(item, cart=None):
    if cart is None:
        cart = []
    cart.append(item)
    return cart
```

### Мини-итог

`*args`/`**kwargs` собирают «лишние» аргументы. `*` делает аргументы keyword-only. Изменяемые значения по умолчанию — классическая ловушка, лечится `None`.

## 3. Области видимости LEGB

Python ищет имя по цепочке:

1. **L**ocal — внутри текущей функции.
2. **E**nclosing — во внешних (объёмлющих) функциях.
3. **G**lobal — на уровне модуля.
4. **B**uilt-in — встроенные имена (`print`, `len`, ...).

```python
x = "global"

def outer():
    x = "enclosing"
    def inner():
        # x = "local"
        print(x)   # найдёт "enclosing"
    inner()

outer()
```

### Пошаговый поиск имени

Python идёт по четырём уровням и берёт **первое** найденное:

```python
x = "global"

def outer():
    x = "enclosing"
    def inner():
        print(x)      # нет локального x → ищем в enclosing → "enclosing"
    inner()

outer()
```

Если закомментировать `x = "enclosing"`, найдётся `"global"`. Если закомментировать и его — `NameError`.

### Что встроено (Built-in)

```python
print(len("abc"))     # len и print — встроенные имена
```

Их можно «перекрыть» (не стоит):

```python
# ❌ перекрыли встроенный list
list = [1, 2, 3]
# list([4, 5])   # TypeError — list теперь не функция

# ✅ не используй имена встроенных функций
```

### Локальная область

```python
def f():
    y = 10        # локальная переменная
    return y

f()
# print(y)        # ❌ NameError — y существует только внутри f
```

### Мини-итог

LEGB — порядок поиска: Local → Enclosing → Global → Built-in. Первое совпадение выигрывает. Не затеняй встроенные имена.

## 4. `global` и `nonlocal`

По умолчанию присваивание создаёт **локальную** переменную.

```python
count = 0

def inc():
    global count
    count += 1     # меняем глобальную

def make_counter():
    n = 0
    def step():
        nonlocal n
        n += 1
        return n
    return step
```

- `global` — изменяет переменную модуля.
- `nonlocal` — изменяет переменную ближайшей внешней функции (не глобальной).

**Нюанс:** изменять *содержимое* изменяемого объекта можно и без `global`/`nonlocal`:
```python
data = []
def add():
    data.append(1)   # работает без global
```

### Почему без `global` чтение работает, а запись — нет

```python
x = 10

def read():
    print(x)      # ✅ читаем глобальную

def write_bad():
    x = 20        # создаёт ЛОКАЛЬНУЮ x, глобальная не меняется

def write_good():
    global x
    x = 20        # ✅ меняем глобальную
```

### Наглядный пример с `nonlocal`

```python
def make_counter():
    n = 0
    def step():
        nonlocal n     # ссылаемся на n из make_counter
        n += 1
        return n
    return step

counter = make_counter()
print(counter())   # 1
print(counter())   # 2
print(counter())   # 3
```

### Мутация изменяемого объекта без объявлений

```python
data = []

def add():
    data.append(1)   # ✅ НЕ присваивание имени, а мутация объекта

add()
print(data)          # [1]
```

Разница: `data.append` меняет объект, а `data = ...` переприсваивает имя.

### Сравнительная таблица

| Ключевое слово | Что меняет | Область |
|---|---|---|
| (нет) | создаёт локальную | local |
| `global` | переменную модуля | global |
| `nonlocal` | переменную внешней функции | enclosing |

### Мини-итог

Присваивание по умолчанию локально. `global`/`nonlocal` нужны только когда меняем имя во внешней области. Мутация объекта в этом не нуждается.

## 5. Замыкания (closures)

Замыкание — функция, которая «запоминает» переменные из внешней области, даже после её завершения.

```python
def multiplier(factor):
    def multiply(x):
        return x * factor   # factor захвачен из внешней функции
    return multiply

double = multiplier(2)
double(5)   # 10
```

Классическая ловушка в цикле:
```python
funcs = [lambda: i for i in range(3)]
[f() for f in funcs]   # [2, 2, 2] — все захватили одну переменную i

funcs = [lambda i=i: i for i in range(3)]   # ✅ фиксируем через default
[f() for f in funcs]   # [0, 1, 2]
```

### Что такое замыкание на примере

```python
def outer():
    message = "привет"

    def inner():
        print(message)     # запоминает message из outer

    return inner

fn = outer()      # outer завершилась, но message жив в замыкании
fn()              # привет
```

### Зачем нужны замыкания

- Создание «функций с памятью» (счётчики, множители).
- Декораторы (День 7).
- Настройка поведения без глобальных переменных.

```python
def make_multiplier(n):
    return lambda x: x * n

times2 = make_multiplier(2)
times10 = make_multiplier(10)
print(times2(5))    # 10
print(times10(5))   # 50
```

### Пошаговый разбор ловушки late binding

```python
funcs = []
for i in range(3):
    funcs.append(lambda: i)   # лямбда захватывает ИМЯ i, не значение

print([f() for f in funcs])   # [2, 2, 2]
```

К моменту вызова цикл завершился, и `i == 2`. Все лямбды видят одно и то же имя.

```python
# ✅ Фиксируем значение через default-аргумент
funcs = [lambda i=i: i for i in range(3)]
print([f() for f in funcs])   # [0, 1, 2]
```

### Мини-итог

Замыкание = функция + захваченные переменные внешней области. Ловушка late binding: захватывается имя, а не значение, поэтому в цикле фиксируй через `i=i`.

## 6. Функции высших порядков и первого класса

- **Функция первого класса** — её можно присвоить переменной, передать, вернуть.
- **Функция высших порядков** — принимает или возвращает функцию.

```python
from functools import reduce

nums = [1, 2, 3, 4]
list(map(lambda x: x * 2, nums))          # [2, 4, 6, 8]
list(filter(lambda x: x % 2 == 0, nums))  # [2, 4]
reduce(lambda a, b: a + b, nums)          # 10
sorted(nums, key=lambda x: -x)            # [4, 3, 2, 1]
```

> Часто `map`/`filter` заменяют comprehension'ами — читается лучше.

### `map`, `filter`, `reduce`

```python
nums = [1, 2, 3, 4]

# map — применить функцию к каждому
print(list(map(str, nums)))              # ['1', '2', '3', '4']

# filter — оставить подходящие
print(list(filter(lambda x: x > 2, nums)))  # [3, 4]

# reduce — свернуть в одно значение
from functools import reduce
print(reduce(lambda a, b: a + b, nums, 0))  # 10
```

### Замена comprehension'ом

```python
# map/filter
list(map(lambda x: x * 2, nums))
list(filter(lambda x: x % 2 == 0, nums))

# ✅ читаемее
[x * 2 for x in nums]
[x for x in nums if x % 2 == 0]
```

### `sorted` с ключом

```python
words = ["banana", "kiwi", "apple"]
print(sorted(words, key=len))    # ['kiwi', 'apple', 'banana']
```

### Мини-итог

Функции — первоклассные объекты, поэтому их можно передавать в `map`/`filter`/`sorted`. Для простых преобразований comprehension читаемее.

## 7. Анонимные функции `lambda`

```python
square = lambda x: x * x
```
Ограничение: только одно выражение, без `return` и statements. Хороши как `key=`/короткие callback.

### Синтаксис

`lambda аргументы: выражение` — результат выражения возвращается автоматически.

```python
add = lambda a, b: a + b
print(add(2, 3))     # 5

# То же через def
def add2(a, b):
    return a + b
```

### Где lambda уместна

```python
pairs = [("b", 2), ("a", 1)]
print(sorted(pairs, key=lambda p: p[1]))    # [('a', 1), ('b', 2)]
print(list(map(lambda x: x ** 2, [1, 2, 3])))  # [1, 4, 9]
```

### Где lambda не нужна

```python
# ❌ Плохо: бессмысленное имя
square = lambda x: x * x

# ✅ Лучше обычная функция
def square(x):
    return x * x

# ❌ Сложная логика в lambda
# f = lambda x: x*2 if x > 0 else -x if x < 0 else 0
```

### Мини-итог

`lambda` — короткая безымянная функция из одного выражения. Уместна в `key=` и callback'ах, но для именованной логики лучше `def`.

## 8. Рекурсия (базово)

Функция, вызывающая саму себя, должна иметь **базовый случай** (условие выхода).

```python
def factorial(n):
    if n <= 1:        # базовый случай
        return 1
    return n * factorial(n - 1)

print(factorial(5))   # 120
```

### Без базового случая — переполнение

```python
def infinite(n):
    return infinite(n + 1)   # ❌ RecursionError
```

### Мини-итог

Рекурсия элегантна для древовидных задач, но ограничена глубиной стека (~1000). Подробнее — в углублённой теории.

## 9. Что спрашивают

- `*args` vs `**kwargs`?
- Что такое изменяемый аргумент по умолчанию и чем он опасен?
- Объясни LEGB.
- `global` vs `nonlocal`?
- Что такое замыкание? Приведи пример.
- Почему `[lambda: i for i in range(3)]` даёт `[2,2,2]`?

### Разборы

**`*args` vs `**kwargs`?** `*args` собирает позиционные в кортеж, `**kwargs` — именованные в словарь.

**Опасный дефолт?** Значение вычисляется один раз и сохраняется между вызовами; изменяемый дефолт накапливает состояние.

**LEGB?** Local → Enclosing → Global → Built-in.

**`global` vs `nonlocal`?** `global` меняет переменную модуля, `nonlocal` — переменную внешней функции.

**`[2,2,2]`?** Late binding: лямбды захватывают имя `i`, к моменту вызова оно равно 2.

## 10. Частые ошибки (сводка)

```python
# ❌ 1. Изменяемый дефолт
def bad(x, acc=[]): ...

# ✅
def good(x, acc=None):
    acc = [] if acc is None else acc

# ❌ 2. Ожидание, что присваивание внутри функции меняет глобальную
x = 1
def f():
    x = 2      # локальная!
f()
print(x)       # 1

# ✅
def f():
    global x
    x = 2

# ❌ 3. Late binding в цикле
funcs = [lambda: i for i in range(3)]

# ✅
funcs = [lambda i=i: i for i in range(3)]

# ❌ 4. Затенение встроенных имён
list = [1, 2, 3]
```

## 11. Мини-итог дня

1. Функция — объект первого класса.
2. `*args`/`**kwargs` собирают аргументы; `*` — keyword-only.
3. Значения по умолчанию вычисляются один раз → изменяемый дефолт опасен.
4. Поиск имён — LEGB.
5. `global`/`nonlocal` нужны только для переприсваивания имени.
6. Замыкание захватывает переменные; в цикле фиксируй значение через `i=i`.
