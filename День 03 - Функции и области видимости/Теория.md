# День 3 — Функции и области видимости

> Цель: понимать, как передаются аргументы, как работает поиск имён (LEGB) и что такое замыкания.

## 1. Определение и вызов

```python
def greet(name, greeting="Привет"):
    """Документация функции."""
    return f"{greeting}, {name}!"

greet("Аня")                 # 'Привет, Аня!'
greet("Аня", greeting="Хай") # 'Хай, Аня!'
```

- `def` создаёт объект-функцию и привязывает имя.
- Функции — **объекты первого класса**: их можно присваивать, передавать, возвращать.

---

## 2. Аргументы: `*args` и `**kwargs`

```python
def func(pos, *args, key=1, **kwargs):
    print(pos, args, key, kwargs)

func(1, 2, 3, key=9, a=10, b=20)
# 1 (2, 3) 9 {'a': 10, 'b': 20}
```

- `*args` — позиционные аргументы как **кортеж**.
- `**kwargs` — именованные как **словарь**.
- Параметры после `*` — **только именованные** (keyword-only).

**Распаковка при вызове:**
```python
def add(a, b): return a + b
args = (2, 3); kwargs = {"a": 2, "b": 3}
add(*args)      # 5
add(**kwargs)   # 5
```

**Ловушка изменяемого аргумента по умолчанию:**
```python
def bad(x, acc=[]):     # ❌ список создаётся один раз!
    acc.append(x)
    return acc
bad(1)   # [1]
bad(2)   # [1, 2]  ← неожиданно

def good(x, acc=None):  # ✅
    if acc is None:
        acc = []
    acc.append(x)
    return acc
```

## 3. Области видимости LEGB

Python ищет имя по цепочке:

1. **L**ocal — внутри текущей функции.
2. **E**nclosing — во внешних (объёмлющих) функциях.
3. **G**lobal — на уровне модуля.
4. **B**uilt-in — встроенные имена (`print`, `len`, ...).

```python
x = "global"

def outer():
    x = "enclosing"
    def inner():
        # x = "local"
        print(x)   # найдёт "enclosing"
    inner()

outer()
```

## 4. `global` и `nonlocal`

По умолчанию присваивание создаёт **локальную** переменную.

```python
count = 0

def inc():
    global count
    count += 1     # меняем глобальную

def make_counter():
    n = 0
    def step():
        nonlocal n
        n += 1
        return n
    return step
```

- `global` — изменяет переменную модуля.
- `nonlocal` — изменяет переменную ближайшей внешней функции (не глобальной).

**Нюанс:** изменять *содержимое* изменяемого объекта можно и без `global`/`nonlocal`:
```python
data = []
def add():
    data.append(1)   # работает без global
```

## 5. Замыкания (closures)

Замыкание — функция, которая «запоминает» переменные из внешней области, даже после её завершения.

```python
def multiplier(factor):
    def multiply(x):
        return x * factor   # factor захвачен из внешней функции
    return multiply

double = multiplier(2)
double(5)   # 10
```

Классическая ловушка в цикле:
```python
funcs = [lambda: i for i in range(3)]
[f() for f in funcs]   # [2, 2, 2] — все захватили одну переменную i

funcs = [lambda i=i: i for i in range(3)]   # ✅ фиксируем через default
[f() for f in funcs]   # [0, 1, 2]
```

## 6. Функции высших порядков и первого класса

- **Функция первого класса** — её можно присвоить переменной, передать, вернуть.
- **Функция высших порядков** — принимает или возвращает функцию.

```python
from functools import reduce

nums = [1, 2, 3, 4]
list(map(lambda x: x * 2, nums))          # [2, 4, 6, 8]
list(filter(lambda x: x % 2 == 0, nums))  # [2, 4]
reduce(lambda a, b: a + b, nums)          # 10
sorted(nums, key=lambda x: -x)            # [4, 3, 2, 1]
```

> Часто `map`/`filter` заменяют comprehension'ами — читается лучше.

## 7. Анонимные функции `lambda`

```python
square = lambda x: x * x
```
Ограничение: только одно выражение, без `return` и statements. Хороши как `key=`/короткие callback.
