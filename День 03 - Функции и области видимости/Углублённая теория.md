## 1. Полный порядок параметров

```python
def f(pos_only, /, normal, *, kw_only):
    ...
```

- До `/` — **только позиционные**.
- После `*` — **только именованные** (keyword-only).
- `*args` собирает лишние позиционные, `**kwargs` — именованные.

Вызов с `*`/`**` распаковывает:
```python
args = (1, 2); kwargs = {"a": 3}
f(*args, **kwargs)
```

## 2. Значения по умолчанию вычисляются при определении

```python
import time
def log(msg, t=time.time()):   # time.time() вызовется ОДИН раз
    print(t, msg)
```

Отсюда ловушка с изменяемым `acc=[]`. Проверка — `f.__defaults__` (позиционные) и `f.__kwdefaults__` (именованные).

## 3. Замыкания и ячейки

Замыкание хранит переменные во **ячейках** (`cell`):

```python
def outer():
    x = 10
    def inner():
        return x
    return inner

fn = outer()
fn.__closure__[0].cell_contents   # 10
```

**Late binding** в цикле:
```python
funcs = [lambda: i for i in range(3)]     # все -> 2
funcs = [lambda i=i: i for i in range(3)] # 0,1,2
```
Причина: лямбда захватывает **имя**, а не значение на момент создания.

## 4. `nonlocal` и изменяемое состояние

```python
def make_counter():
    n = 0
    def inc():
        nonlocal n
        n += 1
        return n
    return inc
```

Альтернатива — класс или `itertools.count`.

## 5. Функции как объекты: атрибуты и интроспекция

```python
def f(a: int, b: int = 1) -> int:
    """doc"""
    return a + b

f.__name__        # 'f'
f.__doc__         # 'doc'
f.__annotations__ # {'a': int, 'b': int, 'return': int}
f.__defaults__    # (1,)
f.__code__.co_varnames   # ('a', 'b')
```

`inspect.signature(f)` даёт полную сигнатуру — так работают декораторы и фреймворки.

## 6. Функциональные инструменты

- **`functools.partial`** — фиксирует часть аргументов.
- **`functools.reduce`** — свёртка.
- **`functools.lru_cache` / `cache`** — мемоизация.
- **`functools.singledispatch`** — перегрузка по типу (аналог множественной диспетчеризации).

```python
from functools import partial, reduce, lru_cache, singledispatch

add10 = partial(lambda a, b: a + b, 10)
reduce(lambda a, b: a * b, [1, 2, 3, 4])   # 24

@lru_cache(maxsize=None)
def fib(n): return n if n < 2 else fib(n-1) + fib(n-2)

@singledispatch
def show(x): return "unknown"
@show.register
def _(x: int): return "int"
```

## 7. Callable-объекты

Любой объект с `__call__` — вызываемый:

```python
class Adder:
    def __init__(self, n): self.n = n
    def __call__(self, x): return x + self.n

add5 = Adder(5)
add5(10)   # 15
callable(add5)  # True
```

Так работают декораторы-классы и «функции с состоянием».

## 8. Рекурсия: ограничения и замена

- Нет оптимизации хвостовой рекурсии (TCO).
- Ограничение глубины: `sys.getrecursionlimit()` (по умолчанию ~1000).
- Глубокая рекурсия → `RecursionError`; иногда помогает перевод на итерацию со стеком.

```python
def fact(n, acc=1):
    return acc if n <= 1 else fact(n-1, acc*n)
```

## 9. Полезные мелочи

- **Walrus `:=`**: `if (n := len(a)) > 10: ...`.
- **Слияние словарей**: `a | b` (3.9+).
- **Распаковка в вызове**: `f(*args, **kwargs)`.
- **`enumerate`/`zip`/`reversed`** — читаемее ручных индексов.
