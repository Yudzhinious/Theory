# День 1 — Вопросы

Ответь вслух, потом проверь себя. Вопросы отсортированы от простых к сложным.

---

**1. Что такое динамическая типизация?**
<details><summary>Ответ</summary>
Тип переменной определяется во время выполнения, а не при объявлении. Одна и та же переменная может поочерёдно ссылаться на объекты разных типов.
</details>

**2. Чем `is` отличается от `==`?**
<details><summary>Ответ</summary>
`is` сравнивает идентичность объектов (адреса, `id`), `==` — значения через `__eq__`. Пример: два одинаковых списка `==`, но не `is`.
</details>

**3. Что выведет код и почему?**
```python
a = [1, 2, 3]
b = a
b.append(4)
print(a)
```
<details><summary>Ответ</summary>
`[1, 2, 3, 4]`. `b` и `a` ссылаются на один объект; `append` изменяет сам объект.
</details>

**4. Назови изменяемые и неизменяемые типы.**
<details><summary>Ответ</summary>
Изменяемые: `list`, `dict`, `set`, `bytearray`. Неизменяемые: `int`, `float`, `str`, `tuple`, `frozenset`, `bytes`, `bool`, `None`.
</details>

**5. Почему `257 is 257` может быть `False`, а `256 is 256` — `True`?**
<details><summary>Ответ</summary>
CPython кэширует (интернирует) целые от -5 до 256. Числа вне этого диапазона создаются как отдельные объекты, поэтому `is` даёт `False`.
</details>

**6. Можно ли использовать `is` для сравнения чисел/строк?**
<details><summary>Ответ</summary>
Не рекомендуется. `is` — только для `None`, `True`, `False`. Для значений — `==`.
</details>

**7. Что произойдёт при конкатенации строк в цикле?**
```python
s = ""
for i in range(1000):
    s += str(i)
```
<details><summary>Ответ</summary>
Строки неизменяемы — каждый `+=` создаёт новую строку и копирует старую, это O(n²) по памяти/времени. Лучше собрать список и сделать `"".join(parts)`.
</details>

**8. Что вернёт `type(True)` и почему `True == 1`?**
<details><summary>Ответ</summary>
`<class 'bool'>`. `bool` — подкласс `int`, поэтому `True == 1` и `False == 0`.
</details>

**9. Как развернуть строку?**
<details><summary>Ответ</summary>
Срезом с шагом -1: `s[::-1]`.
</details>

**10. Что такое `None`? Это `False`?**
<details><summary>Ответ</summary>
`None` — единственный экземпляр `NoneType`, означает «отсутствие значения». В булевом контексте `bool(None) is False`, но `None == False` → `False`.
</details>

## Мини-задача
Напиши функцию, которая меняет местами значения двух переменных, и объясни, почему в Python это можно сделать без временной переменной.
<details><summary>Решение</summary>

```python
a, b = 1, 2
a, b = b, a   # правая часть вычисляется в кортеж, затем распаковывается
```
</details>
