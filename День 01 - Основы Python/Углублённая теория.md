## 1. Всё есть объект: структура `PyObject`

В CPython любой объект начинается с двух полей:

```c
typedef struct {
    Py_ssize_t ob_refcnt;   // счётчик ссылок
    PyTypeObject *ob_type;  // указатель на тип
} PyObject;
```

- Переменная — это **имя в пространстве имён** (namespace), указывающее на объект.
- Присваивание `a = b` **не копирует** объект, а добавляет ссылку (+1 к refcount).
- `del a` уменьшает refcount; при 0 объект освобождается.

```python
import sys
a = []
b = a
sys.getrefcount(a)   # 3 (a, b и временный аргумент getrefcount)
```

## 2. Кэширование и интернирование

- **Small int cache:** целые `-5..256` создаются один раз при старте.
- **String interning:** строки, похожие на идентификаторы (буквы/цифры/`_`), могут кэшироваться. Компилятор интернирует строковые литералы.
- **`sys.intern(s)`** — принудительно интернировать строку (ускоряет сравнение по `is` в словарях-ключах).

```python
import sys
sys.intern("long_string_...")   # теперь одна ссылка на равные строки
```

Интернирование — оптимизация **CPython**, а не гарантия языка. Не полагайся на `is` для строк.

## 3. `__eq__`, `__hash__` и контракт равенства

Правило: **если `a == b`, то `hash(a) == hash(b)`** (обратное неверно).

- Переопределяя `__eq__`, ты **теряешь** автоматический `__hash__` (он становится `None`) → объект нельзя класть в `set`/`dict`.
- Для неизменяемых объектов задавай `__hash__` вручную.

```python
class Point:
    def __init__(self, x, y): self.x, self.y = x, y
    def __eq__(self, o): return (self.x, self.y) == (o.x, o.y)
    def __hash__(self): return hash((self.x, self.y))
```

**Hash randomization:** хеши строк рандомизируются при старте (`PYTHONHASHSEED`), чтобы защититься от hash-DoS. Поэтому порядок `set` между запусками может отличаться.

## 4. Истинность (`truthiness`)

`bool(x)` использует `__bool__`, а если его нет — `__len__`:

```python
bool([]) == False
bool(0) == False
bool("") == False
bool(None) == False
bool(object()) == True     # объект без __bool__/__len__ всегда истинен
```

Ловушка: `if x:` для числовых значений `0` может быть нежелательно — используй `if x is not None:`.

## 5. Числа: int, float, Decimal

- **`int`** — произвольной точности (big int). `sys.getsizeof(2**100)` растёт.
- **`float`** — IEEE 754 двойной точности. Классика:

```python
0.1 + 0.2 == 0.3        # False!
round(0.1 + 0.2, 2)     # 0.3
math.isclose(0.1 + 0.2, 0.3)   # True
```

- **`Decimal`** — точная десятичная арифметика (деньги).
- **`Fraction`** — рациональные числа.
- Сравнение float — через `math.isclose`, не `==`.

```python
from decimal import Decimal
Decimal("0.1") + Decimal("0.2") == Decimal("0.3")   # True
```

## 6. Строки и кодировки

- `str` — последовательность **Unicode-кодовых точек**; `bytes` — последовательность байт.
- `s.encode("utf-8")` → `bytes`; `b.decode("utf-8")` → `str`.
- `len(s)` — число символов, `len(s.encode())` — число байт (разные для кириллицы!).

```python
len("привет")                 # 6 символов
len("привет".encode("utf-8")) # 12 байт
```

- **Ошибки кодирования:** `encode(..., errors="ignore"/"replace"/"strict")`.
- Открывай файлы с явным `encoding="utf-8"`.
- Строки неизменяемы; `+=` в цикле — O(n²), используй `"".join(list)`.

## 7. `None`, sentinel и `type` vs `isinstance`

- `None` — единственный экземпляр `NoneType`, сравнивай через `is`.
- Для «отсутствия значения, отличного от None» используют уникальный sentinel-объект: `_MISSING = object()`.
- `type(x) is T` — строгое совпадение; `isinstance(x, T)` — учитывает наследование.
- `isinstance` принимает кортеж/`Union`: `isinstance(x, (int, float))`.

## 8. `id()` и его подвох

`id()` возвращает адрес. **Адрес может переиспользоваться** после удаления объекта:

```python
a = [1, 2]
print(id(a))
del a
b = [3, 4]
print(id(b))   # может совпасть с прежним id(a)
```

Поэтому `id` — не «уникальный идентификатор навсегда».
