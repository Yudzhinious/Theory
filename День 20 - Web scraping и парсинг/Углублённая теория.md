## 1. HTTP-сессии и надёжность

```python
import requests
s = requests.Session()
s.headers.update({"User-Agent": "Mozilla/5.0"})
s.get(url)   # cookies и соединение переиспользуются
```

- **Redirects** — `allow_redirects`, `history`.
- **Retries + backoff:** `HTTPAdapter` + `Retry`, экспоненциальная задержка + jitter.
- **Таймауты** обязательны (connect/read).
- **Прокси:** `proxies={"https": "http://..."}`.
- **Сжатие** (gzip/br) обрабатывается автоматически.

```python
from requests.adapters import HTTPAdapter
from urllib3.util.retry import Retry
retry = Retry(total=3, backoff_factor=0.5, status_forcelist=[429, 500, 502, 503])
s.mount("https://", HTTPAdapter(max_retries=retry))
```

## 2. Селекторы: CSS, XPath, JSONPath

- **CSS:** `div.item > a.link`, `.price`, `#main a[href]`, `:nth-child`.
- **XPath:** `/html/body//a[@class='x']`, `//span[contains(text(),'цена')]`.
- **lxml** быстрее; поддерживает XPath нативно.
- **JSONPath** для JSON-API (`$..price`), `jmespath`.

```python
from lxml import html
tree = html.fromstring(page)
prices = tree.xpath("//span[@class='price']/text()")
```

## 4. Динамические страницы

- **Playwright** (совр.) / **Selenium** — управляют реальным браузером.
- Ожидания: `wait_for_selector`, `wait_for_load_state`.
- Перехват сетевых запросов — можно брать данные из XHR/API вместо парсинга DOM.
- Headless-режим для серверов; stealth-плагины против детекции.

```python
page.goto(url)
page.wait_for_selector(".results")
items = page.query_selector_all(".item")
```

## 5. Асинхронный scraping

```python
import asyncio, aiohttp

async def fetch(session, url, sem):
    async with sem:                      # ограничение конкурентности
        async with session.get(url) as r:
            return await r.text()

async def main(urls):
    sem = asyncio.Semaphore(10)
    async with aiohttp.ClientSession() as s:
        return await asyncio.gather(*(fetch(s, u, sem) for u in urls))

asyncio.run(main(urls))
```

**Semaphore** защищает и сервер, и тебя (rate limit).

## 6. Scrapy (фреймворк)

- **Spiders** — логика обхода; **Items** — структуры данных; **Pipelines** — очистка/сохранение; **Middlewares** — прокси, headers, retry.
- Асинхронный из коробки, дедупликация, throttling, `robots.txt` по умолчанию.
- Планирование: cron, Airflow, Celery.

```bash
scrapy startproject myproject
scrapy crawl myspider -o out.json
```

## 7. Anti-bot и обход (этично!)

- CAPTCHA, Cloudflare, fingerprinting (TLS/JA3, canvas), динамические токены.
- Средства: ротация прокси/User-Agent, паузы, headless-браузер, официальные API.
- **Сначала ищи API или данные в JSON** — часто проще и легальнее.
- **Не обходи** защиты, если это нарушает ToS/закон.

---

## 8. Правовые и этические аспекты

- **robots.txt** — уважай.
- **ToS** сайта — читай.
- **Персональные данные** (GDPR, 152-ФЗ) — не собирай без оснований.
- **Авторские права** на контент.
- Нагрузка: не «долби» сервер, ставь паузы и лимиты.
