# День 20 — Web scraping и парсинг

> Цель: уметь забрать данные со страницы/API, распарсить и не нарушить правила.

---

## 1. Что такое scraping vs parsing

- **Scraping** — автоматизированный сбор данных с веб-страниц.
- **Parsing** — разбор полученного контента (HTML/XML/JSON) и извлечение нужных полей.

Пайплайн: **запрос → получение ответа → разбор → извлечение → сохранение**.

---

## 2. HTTP-запросы: `requests`

```python
import requests

resp = requests.get(
    "https://example.com/api/items",
    params={"page": 1},
    headers={"User-Agent": "Mozilla/5.0"},
    timeout=10,
)
resp.raise_for_status()        # выбросит исключение при 4xx/5xx
data = resp.json()             # если API отдаёт JSON
html = resp.text               # если HTML
```

- `params` — query-параметры.
- `headers` — важно для `User-Agent`, `Accept`.
- `timeout` — обязателен, чтобы не зависнуть.
- `raise_for_status()` — проверка кода ответа.
- `requests.Session()` — переиспользование соединения и cookies.

> Всегда предпочитай **API (JSON)**, если он есть: стабильнее и быстрее, чем парсинг HTML.

---

## 3. Парсинг HTML: BeautifulSoup

```python
from bs4 import BeautifulSoup

soup = BeautifulSoup(html, "html.parser")   # или "lxml" (быстрее)
title = soup.find("h1").get_text(strip=True)
links = [a["href"] for a in soup.select("a.item-link")]
```

- `find` / `find_all` — поиск по тегу/атрибуту.
- `select` — CSS-селекторы (`.class`, `#id`, `div > a`).
- `get_text(strip=True)` — текст без лишних пробелов.
- `lxml` быстрее встроенного `html.parser`.

## 4. Динамические страницы: Selenium / Playwright

Если контент рендерится JavaScript, обычный `requests` его не увидит. Нужен браузер:

```python
from playwright.sync_api import sync_playwright

with sync_playwright() as p:
    browser = p.chromium.launch()
    page = browser.new_page()
    page.goto("https://example.com")
    page.wait_for_selector(".item")
    html = page.content()
    browser.close()
```

Альтернативы: Selenium, `requests-html`. Минус — медленнее и тяжелее.

## 5. Асинхронный scraping

Для множества запросов — `aiohttp`/`httpx` + `asyncio`.

```python
import asyncio, aiohttp

async def fetch(session, url):
    async with session.get(url) as r:
        return await r.text()

async def main(urls):
    async with aiohttp.ClientSession() as session:
        return await asyncio.gather(*(fetch(session, u) for u in urls))

asyncio.run(main(urls))
```

## 6. JSON API и сохранение данных

```python
import json
data = resp.json()
with open("data.json", "w", encoding="utf-8") as f:
    json.dump(data, f, ensure_ascii=False, indent=2)

# CSV
import csv
with open("data.csv", "w", newline="", encoding="utf-8") as f:
    writer = csv.DictWriter(f, fieldnames=["id", "name"])
    writer.writeheader()
    writer.writerows(data)
```

## 7. Вежливость, правила и защита

- **robots.txt** (`https://site/robots.txt`) — какие пути можно обходить.
- **Rate limiting** — делай паузы (`time.sleep`), не долби сервер.
- **Условия использования (ToS)** — читай, scraping может быть запрещён.
- **User-Agent** — представляйся честно.
- **Ретраи и backoff** при 429/5xx.
- **Anti-bot:** CAPTCHA, Cloudflare, динамические токены — обход может нарушать правила.
- **Юридически:** персональные данные (GDPR/152-ФЗ) — осторожно.

```python
import time, requests
for page in range(1, 6):
    r = requests.get(url, params={"page": page}, timeout=10)
    ...
    time.sleep(1)   # вежливая пауза
```
