## 0. О чём этот день

**Web scraping** — автоматический сбор данных с сайтов. Задача встречается в аналитике,
мониторинге цен, агрегаторах вакансий и т.п. Но забирать данные нужно уважительно и
законно. Здесь — полный путь: от запроса до сохранения и очистки.

> **Аналогия.** Scraping — как поход в библиотеку: вы берёте книгу (запрос), находите
> нужные страницы (парсинг), выписываете цитаты (извлечение) и складываете в тетрадь
> (сохранение). Но нельзя выносить все книги разом и мешать другим читателям.

## 1. Что такое scraping vs parsing

- **Scraping** — автоматизированный сбор данных с веб-страниц.
- **Parsing** — разбор полученного контента (HTML/XML/JSON) и извлечение нужных полей.

Пайплайн: **запрос → получение ответа → разбор → извлечение → сохранение**.

```text
[URL] -> requests/httpx -> [HTML/JSON] -> BeautifulSoup/lxml -> [данные] -> [CSV/БД]
```

### 1.1 Разница на примере

```python
import requests
from bs4 import BeautifulSoup

# scraping: получаем страницу
html = requests.get("https://example.com", timeout=10).text

# parsing: разбираем и извлекаем
soup = BeautifulSoup(html, "html.parser")
title = soup.find("title").get_text(strip=True)
print(title)
```

| Термин | Что делает | Инструменты |
|---|---|---|
| Scraping | Скачивает контент | `requests`, `httpx`, `aiohttp` |
| Parsing | Разбирает и извлекает | `BeautifulSoup`, `lxml`, `json` |
| Crawling | Обходит много страниц по ссылкам | `Scrapy`, своя логика |

## 2. HTTP-запросы: `requests`

```python
import requests

resp = requests.get(
    "https://example.com/api/items",
    params={"page": 1},
    headers={"User-Agent": "Mozilla/5.0"},
    timeout=10,
)
resp.raise_for_status()        # выбросит исключение при 4xx/5xx
data = resp.json()             # если API отдаёт JSON
html = resp.text               # если HTML
```

- `params` — query-параметры.
- `headers` — важно для `User-Agent`, `Accept`.
- `timeout` — обязателен, чтобы не зависнуть.
- `raise_for_status()` — проверка кода ответа.
- `requests.Session()` — переиспользование соединения и cookies.

> Всегда предпочитай **API (JSON)**, если он есть: стабильнее и быстрее, чем парсинг HTML.

### 2.1 Разбор ответа по шагам

```python
resp = requests.get("https://api.github.com/repos/psf/requests", timeout=10)

print(resp.status_code)              # 200
print(resp.headers["Content-Type"])  # application/json; charset=utf-8
print(resp.encoding)                 # кодировка ответа
data = resp.json()                   # словарь Python
print(data["stargazers_count"])      # число звёзд
```

### 2.2 Методы HTTP

| Метод | Назначение | Тело запроса |
|---|---|---|
| GET | Получить данные | Нет |
| POST | Создать ресурс | Есть |
| PUT | Заменить ресурс | Есть |
| PATCH | Частично изменить | Есть |
| DELETE | Удалить | Обычно нет |

### 2.3 Типичные ошибки

```python
# ПЛОХО: без timeout — можно висеть бесконечно
requests.get(url)

# ХОРОШО: всегда timeout
requests.get(url, timeout=10)
```

```python
# ПЛОХО: не проверяем статус — .json() упадёт на HTML-странице ошибки
data = requests.get(url).json()

# ХОРОШО: сначала проверка
r = requests.get(url, timeout=10)
r.raise_for_status()
data = r.json()
```

## 3. Парсинг HTML: BeautifulSoup

```python
from bs4 import BeautifulSoup

soup = BeautifulSoup(html, "html.parser")   # или "lxml" (быстрее)
title = soup.find("h1").get_text(strip=True)
links = [a["href"] for a in soup.select("a.item-link")]
```

- `find` / `find_all` — поиск по тегу/атрибуту.
- `select` — CSS-селекторы (`.class`, `#id`, `div > a`).
- `get_text(strip=True)` — текст без лишних пробелов.
- `lxml` быстрее встроенного `html.parser`.

### 3.1 Разбор примера страницы

```python
html = """
<div class="card" data-id="1">
  <h2 class="title">Ноутбук</h2>
  <span class="price">75 000 ₽</span>
  <a class="link" href="/items/1">Подробнее</a>
</div>
"""

from bs4 import BeautifulSoup
soup = BeautifulSoup(html, "html.parser")

card = soup.find("div", class_="card")
print(card["data-id"])                        # 1
print(card.select_one(".title").get_text())   # Ноутбук
print(card.select_one(".price").get_text())   # 75 000 ₽
print(card.select_one("a.link")["href"])      # /items/1
```

### 3.2 Частые методы BeautifulSoup

| Метод | Что делает |
|---|---|
| `find(tag, attrs)` | Первый подходящий элемент |
| `find_all(...)` | Все подходящие |
| `select(css)` | По CSS-селектору (список) |
| `select_one(css)` | Первый по CSS |
| `.get_text(strip=True)` | Текст без лишних пробелов |
| `tag["href"]` | Значение атрибута |
| `tag.attrs` | Словарь атрибутов |

### 3.3 Типичная ошибка: `None`

```python
# ПЛОХО: если элемент не найден, find вернёт None -> AttributeError
price = soup.find("span", class_="price").text

# ХОРОШО: проверяем или используем безопасный доступ
el = soup.find("span", class_="price")
price = el.get_text(strip=True) if el else None
```

## 4. Динамические страницы: Selenium / Playwright

Если контент рендерится JavaScript, обычный `requests` его не увидит. Нужен браузер:

```python
from playwright.sync_api import sync_playwright

with sync_playwright() as p:
    browser = p.chromium.launch()
    page = browser.new_page()
    page.goto("https://example.com")
    page.wait_for_selector(".item")
    html = page.content()
    browser.close()
```

Альтернативы: Selenium, `requests-html`. Минус — медленнее и тяжелее.

### 4.1 Почему `requests` не видит JS-контент

```text
requests получает исходный HTML с сервера.
JS выполняется в браузере ПОСЛЕ загрузки и дорисовывает элементы.
requests JS не выполняет -> видит пустой <div id="app"></div>.
```

### 4.2 Сравнение инструментов

| Инструмент | JS | Скорость | Вес |
|---|---|---|---|
| `requests` + BS4 | Нет | Быстро | Лёгкий |
| `playwright` | Да | Средне | Тяжёлый |
| `selenium` | Да | Медленнее | Тяжёлый |
| `requests-html` | Частично | Средне | Средний |

### 4.3 Совет: ищи API

Часто данные, которые рисует JS, приходят из XHR/fetch-запроса. Откройте DevTools →
Network, найдите JSON-эндпоинт и обращайтесь к нему напрямую — быстрее и надёжнее,
чем гонять браузер.

## 5. Асинхронный scraping

Для множества запросов — `aiohttp`/`httpx` + `asyncio`.

```python
import asyncio, aiohttp

async def fetch(session, url):
    async with session.get(url) as r:
        return await r.text()

async def main(urls):
    async with aiohttp.ClientSession() as session:
        return await asyncio.gather(*(fetch(session, u) for u in urls))

asyncio.run(main(urls))
```

### 5.1 Ограничение конкурентности

Нельзя запускать тысячи запросов разом — сервер (и вы) пострадаете. `Semaphore`
ограничивает число одновременных запросов.

```python
import asyncio, aiohttp

async def fetch(session, url, sem):
    async with sem:                       # не более N одновременно
        async with session.get(url, timeout=10) as r:
            return await r.text()

async def main(urls):
    sem = asyncio.Semaphore(10)
    async with aiohttp.ClientSession() as session:
        return await asyncio.gather(*(fetch(session, u, sem) for u in urls))
```

| Подход | Когда |
|---|---|
| `requests` в цикле | Немного страниц, простота |
| `ThreadPoolExecutor` | I/O-bound, привычный код |
| `asyncio` + `aiohttp` | Много запросов, максимальная скорость |

## 6. JSON API и сохранение данных

```python
import json
data = resp.json()
with open("data.json", "w", encoding="utf-8") as f:
    json.dump(data, f, ensure_ascii=False, indent=2)

# CSV
import csv
with open("data.csv", "w", newline="", encoding="utf-8") as f:
    writer = csv.DictWriter(f, fieldnames=["id", "name"])
    writer.writeheader()
    writer.writerows(data)
```

### 6.1 Сравнение форматов

| Формат | Плюс | Минус |
|---|---|---|
| JSON | Иерархия, API | Не таблица |
| CSV | Таблицы, Excel | Только плоские данные |
| SQLite/Postgres | Запросы, объёмы | Нужна БД |

### 6.2 `ensure_ascii=False`

```python
json.dumps({"name": "Аня"}, ensure_ascii=False)   # {"name": "Аня"}
json.dumps({"name": "Аня"})                        # {"name": "\u0410\u043d\u044f"}
```

Без `ensure_ascii=False` кириллица превратится в `\uXXXX` — читать неудобно.

## 7. Вежливость, правила и защита

- **robots.txt** (`https://site/robots.txt`) — какие пути можно обходить.
- **Rate limiting** — делай паузы (`time.sleep`), не долби сервер.
- **Условия использования (ToS)** — читай, scraping может быть запрещён.
- **User-Agent** — представляйся честно.
- **Ретраи и backoff** при 429/5xx.
- **Anti-bot:** CAPTCHA, Cloudflare, динамические токены — обход может нарушать правила.
- **Юридически:** персональные данные (GDPR/152-ФЗ) — осторожно.

```python
import time, requests
for page in range(1, 6):
    r = requests.get(url, params={"page": page}, timeout=10)
    ...
    time.sleep(1)   # вежливая пауза
```

### 7.1 Что говорит robots.txt

```text
User-agent: *
Disallow: /admin
Disallow: /private
Crawl-delay: 1
Allow: /
```

| Директива | Смысл |
|---|---|
| `User-agent` | Для кого правило |
| `Disallow` | Что нельзя обходить |
| `Allow` | Исключение из Disallow |
| `Crawl-delay` | Пауза между запросами |

> `robots.txt` — не закон, а вежливая просьба. Его нарушение может быть нарушением ToS.

### 7.2 Ретраи с backoff

```python
import time, requests

def get_with_retry(url, tries=3):
    for attempt in range(tries):
        try:
            r = requests.get(url, timeout=10)
            if r.status_code == 429:
                time.sleep(2 ** attempt)     # 1, 2, 4 сек
                continue
            r.raise_for_status()
            return r
        except requests.RequestException:
            if attempt == tries - 1:
                raise
            time.sleep(2 ** attempt)
```

### 7.3 Этичная шпаргалка

```text
1. Проверь robots.txt и ToS.
2. Есть API? Используй его.
3. Ставь паузы и ограничивай конкурентность.
4. Указывай честный User-Agent с контактом.
5. Не собирай персональные данные без оснований.
6. Кэшируй уже скачанное, не дублируй запросы.
```

## 8. Мини-итог

- Scraping — скачивание, parsing — разбор; пайплайн запрос → разбор → сохранение.
- `requests` + `timeout` + `raise_for_status` — база надёжного запроса.
- BeautifulSoup/lxml — парсинг HTML; CSS-селекторы удобны.
- JS-страницы требуют Playwright/Selenium, но лучше найти API.
- `asyncio` + `Semaphore` ускоряют и защищают сервер.
- Уважай robots.txt, ToS, ставь паузы.
