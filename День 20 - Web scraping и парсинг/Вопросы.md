# День 20 — Вопросы

---

**1. Чем scraping отличается от parsing?**
<details><summary>Ответ</summary>
Scraping — автоматизированный сбор данных со страниц. Parsing — разбор полученного контента (HTML/JSON/XML) и извлечение нужных полей.
</details>

**2. Что предпочтительнее: API или парсинг HTML?**
<details><summary>Ответ</summary>
API (JSON), если доступен: стабильнее, быстрее и обычно легальнее. HTML-парсинг — запасной вариант, когда API нет.
</details>

**3. Какие библиотеки использовать для HTTP-запросов?**
<details><summary>Ответ</summary>
`requests` (синхронно), `httpx`/`aiohttp` (асинхронно). Обязательно задавать `timeout` и проверять статус.
</details>

**4. Как парсить HTML?**
<details><summary>Ответ</summary>
`BeautifulSoup` с парсером `lxml`; поиск через `find`/`find_all` или CSS-селекторы `select`, текст через `get_text(strip=True)`.
</details>

**5. Что делать, если контент рендерится JavaScript?**
<details><summary>Ответ</summary>
Использовать браузерные движки: Playwright, Selenium — они выполняют JS и отдают итоговый DOM. Медленнее обычных запросов.
</details>

**6. Как ускорить scraping множества страниц?**
<details><summary>Ответ</summary>
Асинхронно (`aiohttp`/`httpx` + `asyncio.gather`) или пулом потоков. Учитывать rate limiting сервера.
</details>

**7. Что такое robots.txt?**
<details><summary>Ответ</summary>
Файл на сайте, указывающий, какие пути можно/нельзя обходить ботам. Игнорирование может нарушать правила и привести к блокировке.
</details>

**8. Зачем паузы между запросами?**
<details><summary>Ответ</summary>
Вежливость и защита от блокировок: не перегружать сервер, не получить 429. Плюс ретраи с backoff при ошибках.
</details>

**9. Как сохранить собранные данные?**
<details><summary>Ответ</summary>
В JSON (`json.dump`), CSV (`csv.DictWriter`), БД (SQLAlchemy) или файлы. Указывать `encoding="utf-8"` и `ensure_ascii=False`.
</details>

**10. Какие юридические риски у scraping?**
<details><summary>Ответ</summary>
Нарушение ToS сайта, сбор персональных данных (GDPR/152-ФЗ), авторские права. Нужно проверять правила и закон.
</details>

## Мини-задача
Собери заголовки всех статей с `https://example.com/blog` (HTML с тегами `<h2 class="post-title">`), с паузой между страницами.
<details><summary>Решение</summary>

```python
import time, requests
from bs4 import BeautifulSoup

titles = []
for page in range(1, 4):
    r = requests.get(
        "https://example.com/blog",
        params={"page": page},
        headers={"User-Agent": "Mozilla/5.0"},
        timeout=10,
    )
    r.raise_for_status()
    soup = BeautifulSoup(r.text, "lxml")
    titles += [h.get_text(strip=True) for h in soup.select("h2.post-title")]
    time.sleep(1)

print(titles)
```
</details>
