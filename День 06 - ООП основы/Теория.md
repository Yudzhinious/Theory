## 1. Четыре принципа ООП

- **Инкапсуляция** — сокрытие внутреннего состояния, доступ через интерфейс.
- **Наследование** — новый класс на основе существующего.
- **Полиморфизм** — один интерфейс, разное поведение.
- **Абстракция** — выделение существенного, скрытие деталей.

---

## 2. Класс и экземпляр

```python
class User:
    species = "human"                 # атрибут класса (общий)

    def __init__(self, name, age):    # конструктор
        self.name = name              # атрибут экземпляра
        self.age = age

    def greet(self):                  # метод (self — экземпляр)
        return f"Привет, {self.name}"

u = User("Аня", 20)
u.greet()          # 'Привет, Аня'
User.species       # 'human'
```

- `__init__` — инициализация уже созданного объекта.
- `self` — ссылка на экземпляр, передаётся автоматически.

## 3. Инкапсуляция и name mangling

В Python нет настоящих `private`/`protected`, есть соглашения:

- `_name` — «защищённый» (protected), соглашение «не трогай снаружи».
- `__name` — **name mangling**: интерпретатор переименовывает в `_Класс__name`. Это не настоящая приватность.

```python
class Account:
    def __init__(self):
        self._balance = 0        # protected
        self.__pin = "1234"      # mangled

a = Account()
a._balance          # 0 — доступ есть, но так не принято
a.__pin             # AttributeError
a._Account__pin     # '1234' — обход через mangled имя
```

## 4. `@property` — геттер/сеттер/делитер

Позволяет обращаться к методу как к атрибуту и контролировать доступ.

```python
class Temperature:
    def __init__(self):
        self._celsius = 0

    @property
    def celsius(self):               # геттер
        return self._celsius

    @celsius.setter
    def celsius(self, value):        # сеттер
        if value < -273.15:
            raise ValueError("Ниже абсолютного нуля!")
        self._celsius = value

    @celsius.deleter
    def celsius(self):               # делитер
        del self._celsius

t = Temperature()
t.celsius = 25       # вызывает setter
print(t.celsius)     # 25 — вызывает getter
```

## 5. Наследование и `super()`

```python
class Animal:
    def __init__(self, name):
        self.name = name
    def speak(self):
        raise NotImplementedError

class Dog(Animal):
    def speak(self):
        return f"{self.name}: Гав!"

class Puppy(Dog):
    def speak(self):
        return super().speak() + " (тоненько)"
```

`super()` возвращает прокси к следующему классу в MRO (детали — День 7).

## 6. Полиморфизм и утиная типизация

```python
class Cat:
    def sound(self): return "Мяу"
class Dog:
    def sound(self): return "Гав"

def make_sound(animal):
    return animal.sound()   # важно наличие метода, а не тип

make_sound(Cat())   # 'Мяу'
make_sound(Dog())   # 'Гав'
```

«Если объект ведёт себя как утка — это утка». Python проверяет наличие метода, а не тип.

## 7. `@staticmethod` и `@classmethod`

| | `@staticmethod` | `@classmethod` |
|---|---|---|
| Первый аргумент | нет | `cls` |
| Доступ к атрибутам класса | нет | да |
| Применение | утилиты | альтернативные конструкторы, фабрики |

```python
class Person:
    def __init__(self, name, age):
        self.name, self.age = name, age

    @classmethod
    def from_birth_year(cls, name, year):
        return cls(name, 2026 - year)   # альтернативный конструктор

    @staticmethod
    def is_adult(age):
        return age >= 18

p = Person.from_birth_year("Аня", 2005)
Person.is_adult(20)   # True
```

## 8. Магические (dunder) методы

```python
class Vector:
    def __init__(self, x, y):
        self.x, self.y = x, y
    def __repr__(self):              # для отладки
        return f"Vector({self.x}, {self.y})"
    def __str__(self):               # для пользователя (print)
        return f"({self.x}, {self.y})"
    def __add__(self, other):        # v1 + v2
        return Vector(self.x + other.x, self.y + other.y)
    def __eq__(self, other):         # v1 == v2
        return (self.x, self.y) == (other.x, other.y)
    def __len__(self):
        return 2
```

Популярные: `__init__`, `__repr__`, `__str__`, `__eq__`, `__hash__`, `__len__`, `__getitem__`, `__iter__`, `__call__`, `__enter__/__exit__`.

## 9. `__new__` vs `__init__`

- `__new__` — **создаёт** объект (возвращает экземпляр). Нужен для `tuple`/`str`-подобных и паттернов (singleton).
- `__init__` — **инициализирует** уже созданный объект.

```python
class Singleton:
    _instance = None
    def __new__(cls):
        if cls._instance is None:
            cls._instance = super().__new__(cls)
        return cls._instance
```
