# День 2 — Вопросы

---

**1. Чем `list` отличается от `tuple`? Когда использовать `tuple`?**
<details><summary>Ответ</summary>
`list` изменяемый, `tuple` — нет. `tuple` быстрее, занимает меньше памяти, может быть ключом словаря. Используют для фиксированных наборов данных (координаты, записи) и как ключи.
</details>

**2. Почему поиск в `dict`/`set` в среднем O(1)?**
<details><summary>Ответ</summary>
Это хеш-таблицы: ключ превращается в хеш, по нему вычисляется «ведро». Коллизии разрешаются, поэтому средний случай O(1), худший — O(n).
</details>

**3. Что может быть ключом словаря?**
<details><summary>Ответ</summary>
Только хешируемые (неизменяемые) объекты: `int`, `str`, `tuple` из хешируемых, `frozenset`. `list`/`dict`/`set` — нельзя.
</details>

**4. Что выведет?**
```python
a = [1, 2, 3]
b = a[:]
b.append(4)
print(a, b)
```
<details><summary>Ответ</summary>
`[1, 2, 3] [1, 2, 3, 4]`. Срез создаёт новый список, `a` не меняется.
</details>

**5. Shallow и deep copy — в чём разница?**
<details><summary>Ответ</summary>
`copy.copy` копирует объект верхнего уровня, вложенные объекты остаются общими. `copy.deepcopy` рекурсивно копирует всё. Для вложенных структур нужен `deepcopy`.
</details>

**6. Что выведет?**
```python
t = (1, 2, [3, 4])
t[2].append(5)
print(t)
```
<details><summary>Ответ</summary>
`(1, 2, [3, 4, 5])`. Кортеж неизменяем, но хранит ссылку на изменяемый список, содержимое которого менять можно.
</details>

**7. Сложность проверки `x in collection` для `list` и `set`?**
<details><summary>Ответ</summary>
`list` — O(n) (линейный перебор), `set`/`dict` — O(1) в среднем (хеш).
</details>

**8. Как получить список квадратов чётных чисел от 0 до 9?**
<details><summary>Ответ</summary>
`[x*x for x in range(10) if x % 2 == 0]`
</details>

**9. Зачем `deque`, если есть `list`?**
<details><summary>Ответ</summary>
`deque` даёт O(1) на вставку/удаление с обоих концов, а `list` — O(n) в начале. Идеален для очередей.
</details>

**10. Что такое `defaultdict` и `Counter`?**
<details><summary>Ответ</summary>
`defaultdict` — словарь, создающий значение по умолчанию для отсутствующего ключа (например, `list`). `Counter` — словарь-счётчик частот элементов с методом `most_common`.
</details>

## Мини-задача
Дан список слов. Посчитай, сколько раз встречается каждое слово, и выведи топ-3.
<details><summary>Решение</summary>

```python
from collections import Counter
words = "a b c a b a".split()
print(Counter(words).most_common(3))
# [('a', 3), ('b', 2), ('c', 1)]
```
</details>
