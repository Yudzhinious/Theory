## 0. Как читать этот конспект

Коллекции — это «тара» для данных. Вопрос на собеседовании звучит так: «почему ты выбрал `list`, а не `set`?» Правильный ответ опирается на три вещи: **что нужно хранить**, **как часто искать** и **нужен ли порядок/уникальность**. Поэтому сначала разберём, какие коллекции есть, потом — их сложности, затем — приёмы работы.

---

## 1. Четыре базовые коллекции

| Коллекция | Изменяемая | Упорядоченная | Дубликаты | Доступ | Хранение |
|---|---|---|---|---|---|
| `list` | ✅ | ✅ | ✅ | по индексу O(1) | элементы |
| `tuple` | ❌ | ✅ | ✅ | по индексу O(1) | элементы |
| `dict` | ✅ | ✅ (с 3.7) | ключи — нет | по ключу O(1) | пары ключ→значение |
| `set` | ✅ | ❌ | ❌ | O(1) | уникальные элементы |
| `frozenset` | ❌ | ❌ | ❌ | O(1) | уникальные элементы |

**Хешируемость:** ключом `dict` или элементом `set` может быть только неизменяемый (хешируемый) объект: `int`, `str`, `tuple` (если все элементы хешируемы), `frozenset`. `list`/`dict`/`set` — нельзя.

### Что это за коллекции простыми словами

- **`list`** — как **список покупок**: важен порядок, можно добавлять/удалять, возможны повторы.
- **`tuple`** — как **координата точки (x, y)**: набор фиксирован, менять нельзя.
- **`dict`** — как **телефонная книга**: имя → номер.
- **`set`** — как **список гостей без повторов**: важно только наличие, порядок не важен.

### Примеры создания

```python
lst = [1, 2, 3]
tup = (1, 2, 3)
d = {"a": 1, "b": 2}
s = {1, 2, 3}
fs = frozenset([1, 2, 3])

print(type(lst), type(tup), type(d), type(s), type(fs))
```

### Что может быть ключом

```python
d = {}
d[(1, 2)] = "кортеж можно"     # ✅ кортеж хешируем
d[frozenset([1, 2])] = "можно" # ✅ frozenset хешируем

# d[[1, 2]] = "нельзя"          # ❌ TypeError: unhashable type 'list'
```

### Типичная ошибка

```python
# ❌ Думаем, что dict не сохраняет порядок (устаревшее мнение)
d = {"b": 1, "a": 2}
print(list(d))          # ['b', 'a'] — порядок вставки сохранён (Python 3.7+)

# ❌ Пытаемся положить список в set
# set([[1], [2]])       # TypeError: unhashable type 'list'

# ✅ Преобразуем во что-то хешируемое
set(map(tuple, [[1], [2]]))   # {(1,), (2,)}
```

### Мини-итог

Выбор коллекции — компромисс между порядком, уникальностью и скоростью поиска. Если нужен быстрый поиск — `set`/`dict`; если важен порядок и индексы — `list`/`tuple`.

## 2. Сложности операций (важно для собеседования)

| Операция | `list` | `dict`/`set` |
|---|---|---|
| Доступ по индексу/ключу | O(1) | O(1) средн. |
| Поиск значения | O(n) | O(1) средн. |
| Вставка/удаление в конце | O(1) | — |
| Вставка/удаление в начале | O(n) | — |
| Проверка `in` | O(n) | O(1) средн. |

> Худший случай `dict`/`set` — O(n) из-за коллизий, но в среднем O(1).

### Как это понять интуитивно

- `list` — это ряд пронумерованных ячеек. Найти по номеру — мгновенно. Найти по значению — приходится просматривать всё.
- `set`/`dict` — это шкаф с вычисляемым адресом. Хеш говорит, в какую ячейку смотреть, поэтому поиск почти мгновенный.

### Наглядно: `in` для list vs set

```python
import time

big_list = list(range(1_000_000))
big_set = set(range(1_000_000))

t0 = time.perf_counter()
_ = 999_999 in big_list
t1 = time.perf_counter()
_ = 999_999 in big_set
t2 = time.perf_counter()

print(f"list: {t1 - t0:.6f}")   # дольше
print(f"set:  {t2 - t1:.6f}")   # почти мгновенно
```

### Практический приём

```python
# ❌ O(n) на каждый поиск — внутри цикла O(n*m)
for x in data:
    if x in big_list:
        ...

# ✅ O(1) — превращаем список в множество один раз
lookup = set(big_list)
for x in data:
    if x in lookup:
        ...
```

### Мини-итог

Запомни ключевой контраст: `list` хорош для последовательного обхода, `set`/`dict` — для быстрых проверок и поиска. На собеседовании часто просят «ускорить» код заменой `list` на `set`.

## 3. Срезы (slicing)

Работают для `list`, `tuple`, `str`, `range`.

```python
a = [0, 1, 2, 3, 4, 5]
a[1:4]     # [1, 2, 3]
a[:3]      # [0, 1, 2]
a[3:]      # [3, 4, 5]
a[::2]     # [0, 2, 4]
a[::-1]    # [5, 4, 3, 2, 1] — разворот
```

Срез **создаёт новый объект** (для `list` — копию).

### Синтаксис среза

`a[start:stop:step]` — от `start` включительно до `stop` не включительно с шагом `step`.

```python
a = [0, 1, 2, 3, 4, 5]
print(a[1:4])    # [1, 2, 3]
print(a[::2])    # [0, 2, 4]
print(a[1::2])   # [1, 3, 5]
print(a[-2:])    # [4, 5]
print(a[:-2])    # [0, 1, 2, 3]
print(a[10:])    # [] — выход за границы не ошибка
```

### Шаг и разворот

```python
a = [0, 1, 2, 3, 4, 5]
print(a[::-1])   # [5, 4, 3, 2, 1]  — разворот
print(a[::-2])   # [5, 3, 1]        — с конца через один
```

### Срез создаёт копию

```python
a = [1, 2, 3]
b = a[:]         # поверхностная копия
b.append(4)
print(a, b)      # [1, 2, 3] [1, 2, 3, 4] — a не изменился
```

### Ловушка с изменением при срезе

```python
# ❌ a[:] — это поверхностная копия (shallow)
nested = [[1], [2]]
copy_ = nested[:]
copy_[0].append(99)
print(nested)    # [[1, 99], [2]] — вложенный список общий!
```

### Мини-итог

Срез — мощный инструмент без циклов: разворот `[::-1]`, каждый второй `[::2]`, копия `[:]`. Помни, что для вложенных структур копия поверхностная.

## 4. Comprehension (включения)

Компактная замена циклам `for`.

```python
squares = [x*x for x in range(5)]              # list
evens   = {x for x in range(10) if x % 2 == 0} # set
mapping = {x: x*x for x in range(3)}           # dict
gen     = (x*x for x in range(5))              # generator (ленивый)
```

> Генераторные выражения разбираем в День 4.

### Сравнение с обычным циклом

```python
# Циклом
squares = []
for x in range(5):
    squares.append(x * x)

# Comprehension — короче и обычно быстрее
squares = [x * x for x in range(5)]
```

### Условия и вложенность

```python
# Условие-фильтр (if)
evens = [x for x in range(10) if x % 2 == 0]   # [0, 2, 4, 6, 8]

# Тернарный оператор (if-else) в выражении
labels = ["чёт" if x % 2 == 0 else "нечёт" for x in range(4)]

# Вложенные циклы
pairs = [(x, y) for x in [1, 2] for y in "ab"]
# [(1, 'a'), (1, 'b'), (2, 'a'), (2, 'b')]

# Условие + вложенность
flat = [n for row in [[1, 2], [3, 4]] for n in row]   # [1, 2, 3, 4]
```

### Читаемость

```python
# ❌ Слишком сложно — лучше обычный цикл
result = [x for x in range(100) if x % 2 == 0 if x % 3 == 0 if x > 10]

# ✅ Понятнее
result = [x for x in range(100) if x % 6 == 0 and x > 10]
```

### Мини-итог

Comprehension заменяет `append` в цикле, делает код декларативнее. Но не стоит вкладывать 3+ уровня — теряется читаемость.

## 5. Специализированные коллекции (`collections`)

- `namedtuple` — кортеж с именованными полями.
- `deque` — двусторонняя очередь, O(1) вставка/удаление с обоих концов.
- `Counter` — счётчик элементов (подкласс `dict`).
- `defaultdict` — словарь со значением по умолчанию.
- `OrderedDict` — словарь с явным порядком (с 3.7 обычный `dict` тоже упорядочен).

```python
from collections import deque, Counter, defaultdict

dq = deque([1, 2, 3])
dq.appendleft(0); dq.pop()          # O(1)

cnt = Counter("abracadabra")
cnt.most_common(2)                  # [('a', 5), ('b', 2)]

groups = defaultdict(list)
groups["a"].append(1)               # ключ создаётся автоматически
```

### `namedtuple` — читаемость

```python
from collections import namedtuple

Point = namedtuple("Point", "x y")
p = Point(3, 4)
print(p.x, p.y)     # 3 4 — доступ по имени, а не по индексу
print(p[0])         # 3 — при этом это обычный кортеж
print(p)            # Point(x=3, y=4)
```

### `deque` — быстрые оба конца

```python
from collections import deque

dq = deque([1, 2, 3])
dq.appendleft(0)    # O(1)
dq.append(4)        # O(1)
print(dq)           # deque([0, 1, 2, 3, 4])

# Склоящее окно фиксированного размера
window = deque(maxlen=3)
for x in range(5):
    window.append(x)
print(window)       # deque([2, 3, 4], maxlen=3)
```

### `Counter` — подсчёт

```python
from collections import Counter

c = Counter("abracadabra")
print(c["a"])           # 5
print(c.most_common(2)) # [('a', 5), ('b', 2)]

# Арифметика счётчиков
c1 = Counter(a=2, b=1)
c2 = Counter(a=1, c=3)
print(c1 + c2)          # Counter({'a': 3, 'c': 3, 'b': 1})
print(c1 - c2)          # Counter({'b': 1})
```

### `defaultdict` — без KeyError

```python
from collections import defaultdict

groups = defaultdict(list)
for word in ["apple", "avocado", "banana"]:
    groups[word[0]].append(word)

print(dict(groups))     # {'a': ['apple', 'avocado'], 'b': ['banana']}
```

### Сравнительная таблица

| Коллекция | Отличие | Когда использовать |
|---|---|---|
| `list` | базовый массив | порядок, индексы |
| `tuple` | неизменяемый | фиксированные записи |
| `deque` | O(1) на оба конца | очередь, скользящее окно |
| `Counter` | счётчик | частоты |
| `defaultdict` | авто-значение | группировка |
| `OrderedDict` | `move_to_end` | редко нужен |

### Мини-итог

`collections` даёт готовые решения частых задач: группировка, подсчёт, очередь. Знать их — плюс на собеседовании и в реальном коде.

## 6. Копирование: shallow vs deep

```python
import copy
original = [[1, 2], [3, 4]]

shallow = copy.copy(original)   # или original[:], list(original)
shallow[0][0] = 99
print(original[0][0])           # 99 — вложенные объекты общие!

deep = copy.deepcopy(original)
deep[0][0] = 1
print(original[0][0])           # не изменится
```

**Правило:** `copy.copy` копирует только верхний уровень; `deepcopy` — рекурсивно всё.

### Наглядная схема

```python
import copy

original = [[1, 2], [3, 4]]

shallow = copy.copy(original)
print(original[0] is shallow[0])   # True — внутренние списки общие

deep = copy.deepcopy(original)
print(original[0] is deep[0])      # False — полная копия
```

### Способы сделать поверхностную копию

```python
lst = [1, 2, 3]
a = lst[:]          # срез
b = list(lst)       # конструктор
c = lst.copy()      # метод
d = copy.copy(lst)  # модуль copy
```

### Когда какой нужен

| Ситуация | Копирование |
|---|---|
| Простой список чисел/строк | поверхностное |
| Вложенные списки/словари | `deepcopy` |
| Хочешь изменить только верхний уровень | поверхностное |

### Типичная ошибка

```python
# ❌ Думаем, что копия независима
matrix = [[0] * 3] * 3      # ТРИ ссылки на ОДИН список!
matrix[0][0] = 1
print(matrix)               # [[1, 0, 0], [1, 0, 0], [1, 0, 0]]

# ✅ Правильно
matrix = [[0] * 3 for _ in range(3)]
matrix[0][0] = 1
print(matrix)               # [[1, 0, 0], [0, 0, 0], [0, 0, 0]]
```

### Мини-итог

`copy.copy` — только верхний уровень, `deepcopy` — весь граф объектов. Знаменитая ловушка `[[0]*3]*3` — следствие поверхностного «копирования» через умножение.

## 7. Строки: важное

- Неизменяемы, поддерживают срезы и большинство операций последовательностей.
- `str.join()` эффективнее `+` в цикле.
- Методы возвращают **новую** строку: `s.upper()`, `s.replace()`, `s.strip()`.
- Форматирование: f-строки `f"{x:.2f}"`, `"{:>10}".format(x)`.

### Форматирование

```python
x = 3.14159
print(f"{x:.2f}")      # 3.14
print(f"{x:>10.2f}")   # '      3.14' — выравнивание вправо
print(f"{42:05d}")     # 00042
print(f"{0.25:.0%}")   # 25%
```

### Полезные методы

```python
s = "  Hello, World  "
print(s.strip())               # 'Hello, World'
print(s.lower())               # '  hello, world  '
print(s.replace("l", "L"))     # '  HeLLo, WorLd  '
print("a,b,c".split(","))      # ['a', 'b', 'c']
print("-".join(["a", "b"]))    # 'a-b'
print("World" in s)            # True
```

### Почему `join` лучше `+`

```python
# ❌ O(n²)
out = ""
for w in words:
    out += w

# ✅ O(n)
out = "".join(words)
```

### Мини-итог

Строки — неизменяемые последовательности. Для склейки — `join`, для форматирования — f-строки, для поиска — `in`.

## 8. Что спрашивают

- Чем `list` отличается от `tuple`? Когда `tuple`?
- Почему `dict` быстрый? Что такое хеш-таблица?
- Что может быть ключом словаря?
- Shallow vs deep copy?
- Сложность `in` для `list` и `set`?
- Что вернёт `[1,2,3][::-1]`?

### Разборы

**Чем `tuple` лучше `list`?** Меньше памяти, быстрее, неизменяем → может быть ключом `dict`/элементом `set`. Подходит для фиксированных записей.

**Почему `dict` быстрый?** Хеш-таблица: по ключу вычисляется хеш → индекс ячейки → O(1) в среднем.

**`[1,2,3][::-1]`?** → `[3, 2, 1]`.

## 9. Частые ошибки (сводка)

```python
# ❌ 1. Изменение списка во время итерации
for x in lst:
    if x < 0:
        lst.remove(x)   # пропуски элементов

# ✅
lst = [x for x in lst if x >= 0]

# ❌ 2. list как ключ dict
# {[1]: "x"}            # TypeError

# ✅
{(1,): "x"}

# ❌ 3. [[0]*3]*3 — общие строки
# ✅ [[0]*3 for _ in range(3)]

# ❌ 4. `in` по списку в цикле
# ✅ превратить в set
```

## 10. Мини-итог дня

1. `list`/`tuple` — порядок и индексы; `dict`/`set` — быстрый поиск.
2. Ключи и элементы `set` должны быть хешируемыми.
3. `list` — O(n) на поиск, `dict`/`set` — O(1) в среднем.
4. Срезы создают копию; `[::-1]` — разворот.
5. Comprehension короче циклов, но не злоупотребляй вложенностью.
6. `collections` — готовые структуры под частые задачи.
7. Копия бывает поверхностной и глубокой.

**Связка:** понимание хешируемости пригодится для ключей (День 1), а ленивые генераторные выражения — в Дне 4.
