## 1. `list` — динамический массив

- Хранит **массив указателей** на объекты (сами объекты лежат отдельно).
- При `append` ёмкость растёт с запасом (~1.125x), поэтому `append` — **амортизированно O(1)**.
- Вставка/удаление в середине/начале — O(n) (сдвиг указателей).
- `sys.getsizeof(lst)` считает только массив ссылок, не сами объекты.

```python
import sys
sys.getsizeof([])          # ~56 байт
sys.getsizeof([0]*1000)    # ~8056 байт (только указатели)
```

## 2. `dict` — хеш-таблица (compact dict, 3.6+)

- Начиная с Python 3.6, dict использует **компактное представление** и **сохраняет порядок вставки** (с 3.7 — гарантированно).
- Внутри — открытая адресация, коэффициент заполнения ~2/3, при превышении — resize.
- Средний доступ O(1), худший (много коллизий) — O(n).
- Ключи должны быть **хешируемыми**; при равных хешах сравниваются через `__eq__`.

```python
d = {"a": 1, "b": 2}
d["c"] = 3           # порядок вставки сохраняется
```

`dict` — рабочая лошадка Python: объекты (`__dict__`), модули, `sys.modules` — всё это словари.

## 3. `set` / `frozenset`

- По сути — `dict` без значений (только ключи).
- Операции над множествами: `|`, `&`, `-`, `^`; `issubset`, `issuperset`.
- `frozenset` неизменяем и хешируем → может быть ключом `dict` или элементом `set`.
- Проверка `in` — O(1) в среднем.

```python
a = {1, 2, 3}; b = {3, 4}
a & b     # {3}
a | b     # {1, 2, 3, 4}
```

## 4. `tuple`

- Неизменяемая последовательность; **хешируем**, если все элементы хешируемы.
- Меньше памяти и быстрее `list`.
- Используется для «записей» и как ключ словаря.
- `namedtuple` — читаемость: доступ по имени.

```python
from collections import namedtuple
Point = namedtuple("Point", "x y")
p = Point(1, 2)
p.x        # 1
```

---

## 5. `deque` и другие из `collections`

- **`deque`** — двусвязный список блоков, O(1) на оба конца. `maxlen` для скользящего окна.
- **`Counter`** — счётчик; `most_common`, `elements`, арифметика.
- **`defaultdict`** — фабрика значений по умолчанию.
- **`OrderedDict`** — теперь важен только для `move_to_end`/`popitem(last=False)`.
- **`ChainMap`** — несколько словарей как один (конфиги/окружения).
- **`UserDict`/`UserList`** — удобные базовые классы для наследования.

```python
from collections import deque, defaultdict, ChainMap
dq = deque(maxlen=3)
dq.extend([1, 2, 3, 4])     # хранит [2, 3, 4]
```

## 6. Сортировка и `key`

- `sorted()`/`list.sort()` — **Timsort**, стабильная, O(n log n).
- `key=` вычисляется один раз на элемент (быстрее `cmp`).
- `operator.itemgetter`/`attrgetter` быстрее лямбд.

```python
from operator import itemgetter
rows = [("b", 2), ("a", 1)]
sorted(rows, key=itemgetter(1))     # по числу
```

Сортировка кортежей — по элементам слева направо (лексикографически).

## 7. Копирование и вложенность

```python
import copy
shallow = copy.copy(nested)
deep = copy.deepcopy(nested)
```

- `copy.copy` копирует верхний уровень; вложенные объекты общие.
- `deepcopy` рекурсивно; уважает `__copy__`/`__deepcopy__`.
- Срез `lst[:]`, `list(lst)`, `dict(d)` — поверхностные копии.
- **Правило:** неизменяемые объекты копировать не нужно.

## 8. Полезные встроенные модули

- **`array`** — компактный массив однотипных чисел.
- **`bisect`** — бинарный поиск и вставка в отсортированный список.
- **`heapq`** — куча на списке (min-heap), `nsmallest`/`nlargest`.
- **`itertools`** — комбинаторика и ленивые итераторы.

```python
import bisect, heapq
bisect.insort(lst, x)             # вставка с сохранением порядка
heapq.nlargest(3, data)
```

## 9. Сложности (шпаргалка)

| Операция | list | dict/set | deque |
|---|---|---|---|
| Доступ | O(1) | O(1) ср. | O(n) |
| `in` | O(n) | O(1) ср. | O(n) |
| Вставка в конец | O(1)* | O(1) ср. | O(1) |
| Вставка в начало | O(n) | — | O(1) |

\* амортизированно.
