# День 16 — Вопросы

---

**1. Python — компилируемый или интерпретируемый язык?**
<details><summary>Ответ</summary>
И то, и другое. Исходник компилируется в байт-код, который затем исполняется виртуальной машиной (интерпретация).
</details>

**2. Что такое байт-код?**
<details><summary>Ответ</summary>
Низкоуровневые инструкции для виртуальной машины Python, не привязанные к конкретному железу. Промежуточное представление между исходником и машинным кодом.
</details>

**3. Как посмотреть байт-код функции?**
<details><summary>Ответ</summary>
Через модуль `dis`: `dis.dis(func)` или `dis.dis("код")`.
</details>

**4. Что такое `.pyc` и `__pycache__`?**
<details><summary>Ответ</summary>
Кэш скомпилированного байт-кода импортируемых модулей. При неизменном исходнике байт-код берётся из кэша — ускоряет повторный импорт.
</details>

**5. Создаётся ли `.pyc` для главного скрипта?**
<details><summary>Ответ</summary>
Нет. Кэшируются только импортируемые модули; файл, запущенный как `python script.py`, не компилируется в `.pyc`.
</details>

**6. CPython vs PyPy?**
<details><summary>Ответ</summary>
CPython — эталонная реализация на C с GIL. PyPy — реализация с JIT, часто быстрее для CPU-задач, но менее совместима с C-расширениями.
</details>

**7. Что такое JIT?**
<details><summary>Ответ</summary>
Just-In-Time компиляция: перевод «горячих» участков кода в машинный во время выполнения. Быстрее чистой интерпретации, но дольше старт (PyPy, JVM).
</details>

**8. Какие ещё есть реализации Python?**
<details><summary>Ответ</summary>
Jython (JVM), IronPython (.NET), MicroPython (микроконтроллеры), GraalPy. CPython и PyPy — самые распространённые.
</details>

**9. GIL — это часть языка Python?**
<details><summary>Ответ</summary>
Нет, это деталь реализации CPython. В других реализациях (Jython, PyPy) поведение иное. В Python 3.13+ есть экспериментальный free-threaded режим без GIL.
</details>

**10. Что делает `ast.parse`?**
<details><summary>Ответ</summary>
Разбирает исходный код в абстрактное синтаксическое дерево (AST) — этап между парсингом и компиляцией в байт-код.
</details>

## Мини-задача
Посмотри байт-код функции `lambda x: x * 2` и назови основные инструкции.
<details><summary>Решение</summary>

```python
import dis
dis.dis(lambda x: x * 2)
# LOAD_FAST x
# LOAD_CONST 2
# BINARY_OP *
# RETURN_VALUE
```
</details>
