## 1. Конвейер компиляции CPython

```
исходник
  → tokenizer (лексер)
  → parser (PEG, 3.9+) → AST
  → symbol table (области видимости)
  → compiler → code object (байт-код)
  → PVM (интерпретация)
```

- **AST** — дерево синтаксиса (`ast`), используется инструментами (линтеры, рефакторинг).
- **Symbol table** определяет локальные/свободные/глобальные имена.

```python
import ast
ast.dump(ast.parse("x = 1 + 2"), indent=2)
```

## 2. Code object и кадры (frames)

Функция хранит **code object** с метаданными:

```python
def f(a, b=1):
    x = a + b
    return x

f.__code__.co_varnames   # ('a', 'b', 'x')
f.__code__.co_argcount   # 2
f.__code__.co_consts     # (None,)
f.__code__.co_names      # ()
```

- **Frame** — контекст выполнения (локальные, стек, позиция в байт-коде).
- `sys._getframe()`, `inspect.currentframe()` — доступ к кадру.

---

## 3. Байт-код

```python
import dis
dis.dis(f)
```

- Стек-машина: инструкции кладут/снимают значения со стека.
- Частые опкоды: `LOAD_FAST`, `LOAD_CONST`, `LOAD_GLOBAL`, `STORE_FAST`, `BINARY_OP`, `CALL`, `RETURN_VALUE`, `JUMP`.
- `dis.Bytecode(f)` — программный доступ к инструкциям.

```python
import dis
for instr in dis.get_instructions(f):
    print(instr.opname, instr.argval)
```

## 4. Оптимизации компилятора

- **Constant folding:** `1 + 2` сворачивается в `3`.
- **Peephole optimizer** — локальные оптимизации байт-кода.
- `-O` / `-OO` — убирает `assert` и docstrings; задаёт `__debug__ = False`.
- **Specializing adaptive interpreter** (3.11+) — байт-код адаптируется к типам во время выполнения.

---

## 5. `.pyc` и магия

- `.pyc` содержит **magic number** (привязан к версии Python) + timestamp/hash + маршаллизованный code object.
- Несовместимость версий → перекомпиляция.
- Байт-код **можно декомпилировать** (не защита кода).
- `py_compile`, `compileall` — ручная компиляция.

```python
import py_compile
py_compile.compile("module.py")
```

---

## 6. Импорт-система: finders и loaders

- `sys.meta_path` — список **finders** (`PathFinder`, `BuiltinImporter`, `FrozenImporter`).
- Finder возвращает **spec**, loader загружает и исполняет модуль.
- Хуки импорта (PEP 302/451) позволяют кастомную загрузку (zip, сеть).
- `importlib.import_module`, `importlib.util.spec_from_file_location`.

```python
import importlib
mod = importlib.import_module("json")
```

---

## 7. `compile`, `exec`, `eval`

```python
code = compile("x = 1 + 2", "<string>", "exec")
exec(code, {})
eval("2 + 2")            # 4
```

- `exec` — выполнить код; `eval` — вычислить выражение.
- `eval`/`exec` с пользовательским вводом — **опасны** (RCE).

---

## 8. Альтернативные реализации

- **PyPy** — JIT, быстрее CPU-код, но C-расширения работают хуже.
- **Jython/IronPython** — JVM/.NET.
- **MicroPython** — микроконтроллеры.
- **GraalPy** — GraalVM.
- **Free-threaded CPython** (3.13+, PEP 703) — экспериментально без GIL.
- **Cython / mypyc / Nuitka** — компиляция Python в C/машинный код для скорости.
