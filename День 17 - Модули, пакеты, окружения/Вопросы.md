# День 17 — Вопросы

---

**1. Чем модуль отличается от пакета?**
<details><summary>Ответ</summary>
Модуль — файл `.py`. Пакет — каталог с `__init__.py`, объединяющий модули в иерархию.
</details>

**2. Зачем `__init__.py`?**
<details><summary>Ответ</summary>
Помечает каталог как пакет, может содержать код инициализации и реэкспорт имён. В namespace-пакетах (PEP 420) формально не обязателен, но на практике нужен.
</details>

**3. Абсолютный vs относительный импорт?**
<details><summary>Ответ</summary>
Абсолютный — полный путь от корня проекта (предпочтительно, явно). Относительный — внутри пакета через точки (`.`, `..`), работает только при запуске через `python -m`.
</details>

**4. Как Python ищет модуль при импорте?**
<details><summary>Ответ</summary>
Сначала `sys.modules` (кэш), затем встроенные модули, затем каталоги из `sys.path` (каталог скрипта, `PYTHONPATH`, site-packages).
</details>

**5. Зачем `if __name__ == "__main__"`?**
<details><summary>Ответ</summary>
Позволяет выполнять код только при прямом запуске файла, а не при импорте. `__name__` равен `"__main__"` только для точки входа.
</details>

**6. Что такое циклический импорт и как его решить?**
<details><summary>Ответ</summary>
Модуль A импортирует B, а B импортирует A. Решения: вынести общий код в третий модуль, сделать ленивый импорт внутри функции, перестроить зависимости.
</details>

**7. Почему повторный `import` не перезагружает модуль?**
<details><summary>Ответ</summary>
Потому что модуль уже в `sys.modules`. Для принудительной перезагрузки — `importlib.reload(mod)`.
</details>

**8. Зачем виртуальное окружение?**
<details><summary>Ответ</summary>
Изоляция зависимостей проекта от системных и от других проектов, чтобы избежать конфликтов версий.
</details>

**9. Что такое `requirements.txt` и `pyproject.toml`?**
<details><summary>Ответ</summary>
`requirements.txt` — список зависимостей для pip. `pyproject.toml` — современный стандарт описания проекта и зависимостей (PEP 517/518).
</details>

**10. Как узнать сигнатуру функции во время выполнения?**
<details><summary>Ответ</summary>
`inspect.signature(func)` или через `func.__code__` (`co_varnames`, `co_argcount`). Аннотации — `func.__annotations__`.
</details>

## Мини-задача
Дан пакет `shop/` с `models.py`, где есть `Product`. Напиши абсолютный и относительный импорт из `shop/services/order.py`.
<details><summary>Решение</summary>

```python
# абсолютный (предпочтительно)
from shop.models import Product

# относительный (внутри пакета shop)
from ..models import Product
```
</details>
